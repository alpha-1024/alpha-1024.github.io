# 树莓派磁盘分区问题

问题描述：SD 卡大小为 16G，但实际可用空间只有 3.1G。

这通常不是 SD 卡损坏，而是刷入系统时只创建了一个较小的根分区，剩余空间还没有分配给文件系统。

## 解决方案：扩展文件系统

树莓派官方配置工具可以自动把根分区扩展到整张 SD 卡。打开终端运行：

```sh
sudo raspi-config
```

在菜单中选择 **Advanced Options → Expand Filesystem**，确认后退出并重启：

```sh
sudo reboot
```

较新版本的 Raspberry Pi OS 可能会把 `Expand Filesystem` 直接放在主菜单中，看到该选项即可选择。

重启后可以用下面的命令确认空间是否已经扩展：

```sh
df -h /
```

## 空间已满时

如果根分区已经 100% 使用，先清理 APT 缓存，再重新运行配置工具：

```sh
sudo apt-get clean
```

SD 卡长期频繁擦写容易损坏。重要数据应定期备份，生产环境也建议使用更可靠的存储介质。
