# 数学预备：向量、矩阵与线性代数

## 学习目标

学完本篇，你不需要会证明复杂定理，但必须能：

- 说清楚标量、向量、矩阵分别表示什么；
- 判断一个量的单位、维度和所属坐标系；
- 计算范数、点积、叉积、矩阵乘法和齐次变换；
- 解释行列式、逆矩阵、秩、特征值和 SVD 的工程意义；
- 用 NumPy 验证点到平面的距离与最小二乘平面拟合；
- 解释这些知识在 FAST-LIO 中会落到哪一段代码。

## 0. 先建立数学语言

数学不是一堆脱离工程的符号，而是给“可测量的东西”起名字。温度 `25`、时间间隔 `0.01`、角速度 `1.2` 都是数字；当我们补上单位，它们才成为物理量。FAST-LIO 中常见的单位是米（m）、秒（s）、弧度（rad）和米每二次方秒（m/s²）。

### 标量、变量和函数

标量只有一个数值，例如时间 `t=0.1 s`。变量是可以变化的名字，例如位置坐标 `x(t)`。函数描述输入和输出的关系：给定时间，函数 `p(t)` 返回三维位置。

```text
p(t) = [x(t), y(t), z(t)]^T
```

这里的 `T` 表示转置，把一行写成列。`p` 有 3 个分量，因此它是 `3×1` 向量，不是一个普通标量。看到公式时先数维度：维度不匹配的乘法一定是错的。

### 角度与弧度

程序中的 `sin`、`cos` 默认使用弧度。半圈是 `π rad`，一圈是 `2π rad`，角度转弧度的公式是：

```text
弧度 = 角度 × π / 180
```

FAST-LIO 的陀螺仪通常以 rad/s 给出角速度。如果把 90 当作 90 rad，姿态会立刻发散。

## 1. 向量：位置、方向和误差

三维向量写成：

$$
p=\begin{bmatrix}x\\y\\z\end{bmatrix}.
$$

同样的三个数字可能有不同含义：

- 点 `p_L`：LiDAR 坐标系中测得的点，单位 m；
- 速度 `v_W`：世界坐标系中的速度，单位 m/s；
- 小角度误差 `δθ`：旋转误差，单位 rad；
- 法向量 `n`：平面朝向，通常归一化为无量纲单位向量。

因此“看到一个 `Vector3d` 就知道它是什么”是不够的，必须同时记录下标和单位。

### 向量的加减与数乘

只有同维度、同语义的向量才能直接相加：

$$
\begin{bmatrix}1\\2\\3\end{bmatrix}+
\begin{bmatrix}0.1\\-1\\2\end{bmatrix}=
\begin{bmatrix}1.1\\1\\5\end{bmatrix}.
$$

位置加位置通常没有物理意义，但“位置 + 位置误差”有意义；世界系速度不能直接和机体系速度相加。工程代码中最常见的 bug 之一就是把坐标系不同的量混在一起。

### 范数：向量有多长

欧氏范数（L2 范数）为：

$$
\|p\|_2=\sqrt{x^2+y^2+z^2}.
$$

它是点到原点的距离，也是 FAST-LIO 中筛掉过近点、计算邻域半径和判断误差大小的基础。单位向量是长度为 1 的向量：

$$
\hat p=\frac{p}{\|p\|_2},\qquad p\ne0.
$$

归一化前必须检查长度是否接近 0，否则会出现除零。

## 2. 点积：投影、夹角与点面残差

两个三维向量的点积是：

$$
a^Tb=a_xb_x+a_yb_y+a_zb_z.
$$

几何上：

$$
a^Tb=\|a\|\|b\|\cos\theta.
$$

所以点积可以判断方向：正数表示夹角小于 90°，零表示垂直，负数表示大于 90°。把向量 `a` 投影到单位方向 `n` 上，投影长度就是 `n^T a`。

### FAST-LIO 的点到平面距离

平面由单位法向量 `n` 和常数 `d` 定义：

$$
n^Tp+d=0.
$$

对任意点 `p`，有符号距离为：

$$
r=n^Tp+d.
$$

若 `n` 已归一化，`|r|` 就是点到平面的米制距离。FAST-LIO 把当前 LiDAR 点变到世界系后，利用地图近邻估计局部平面，再把 `r` 作为观测残差。这个公式看起来只有一次点积，却连接了坐标变换、最近邻、平面拟合和滤波更新。

## 3. 叉积：旋转产生的位移方向

叉积 `a×b` 得到一个同时垂直于 `a`、`b` 的向量，长度为 `||a||||b||sinθ`。右手定则决定方向：右手四指从 `a` 转向 `b`，拇指方向就是结果。

叉积可写成反对称矩阵：

$$
[a]_\times=\begin{bmatrix}
0&-a_z&a_y\\
a_z&0&-a_x\\
-a_y&a_x&0
\end{bmatrix},\qquad a\times b=[a]_\times b.
$$

例如点 `p` 因小旋转 `δθ` 产生的一阶位移近似为 `-R[p]×δθ`。这就是 FAST-LIO 代码中 `SKEW_SYM_MATRX(point_this)` 出现在姿态 Jacobian 附近的原因：姿态误差会让点沿叉积方向移动。

## 4. 矩阵：批量执行线性变换

矩阵是按行列排列的数字表。一个 `m×n` 矩阵可以把 `n×1` 向量变成 `m×1` 向量：

$$
A_{m\times n}x_{n\times1}=y_{m\times1}.
$$

矩阵乘法的规则是“左边矩阵的列数等于右边矩阵的行数”，并且一般不可交换：`AB != BA`。在坐标变换中，右侧操作先发生，所以 `R1 R2 p` 表示先用 `R2` 旋转，再用 `R1` 旋转。

### 转置、单位矩阵和逆矩阵

转置把行列交换，记作 `A^T`。单位矩阵 `I` 的对角线为 1，满足 `Ix=x`。如果存在 `A^{-1}` 使得 `A^{-1}A=I`，则 `A` 可逆。

旋转矩阵满足：

$$
R^TR=I,\qquad \det(R)=1,\qquad R^{-1}=R^T.
$$

这三条是调试姿态最有价值的检查。数值积分后如果 `R^TR` 明显偏离 `I`，说明旋转更新或归一化出了问题。

### 齐次变换与 `Rp+t`

刚体变换不能只用一个 `3×3` 矩阵表达平移，因此常写成：

$$
T=\begin{bmatrix}R&t\\0&1\end{bmatrix},\qquad
\tilde p=\begin{bmatrix}p\\1\end{bmatrix},\qquad
T\tilde p=\begin{bmatrix}Rp+t\\1\end{bmatrix}.
$$

FAST-LIO 中最关键的点变换是：

$$
p_W=R_I^W(R_L^I p_L+t_L^I)+t_I^W.
$$

从右向左读：先把点从 LiDAR 系变到 IMU 系，再把 IMU 系点旋转到世界系，最后加世界系平移。每一项都要标注坐标系，否则无法判断顺序。

## 5. 线性方程、秩与最小二乘

线性方程组写作 `Ax=b`。如果方程数量和未知数数量不一致，或数据有噪声，通常不存在精确解。此时求：

$$
x^*=\arg\min_x\|Ax-b\|_2^2.
$$

它寻找让所有方程总体误差最小的参数，而不是让某一个点完全吻合。

### 近邻点拟合平面

平面可写成 `z=ax+by+c`。对每个近邻点 `(x_i,y_i,z_i)`，得到：

$$
\begin{bmatrix}x_i&y_i&1\end{bmatrix}
\begin{bmatrix}a\\b\\c\end{bmatrix}=z_i.
$$

五个带噪点通常不能精确同时满足，使用最小二乘估计 `a,b,c`，再构造法向量 `n=[a,b,-1]^T` 并归一化。FAST-LIO 的局部平面拟合本质就是这个问题，只是工程实现会用更稳定的特征分解或 QR 求解。

秩表示独立信息的数量。若所有近邻点几乎落在一条线上，平面参数会不稳定，矩阵秩不足；因此 FAST-LIO 会检查邻域几何是否足够可靠，再决定是否接受该残差。

## 6. 特征值与 SVD 的直觉

特征值问题是 `Av=λv`：矩阵作用后，向量方向不变，只被缩放。协方差矩阵的特征向量描述点云最主要的变化方向，特征值描述沿这些方向的变化大小。

对一组局部点做中心化后：

- 最大特征值方向通常是点云延展最长的方向；
- 最小特征值方向是平面法向方向；
- 如果最小特征值很小，点接近平面；
- 如果两个最小特征值都很小，点可能接近一条线，平面估计不可靠。

SVD 将矩阵分解为 `A=UΣV^T`。工程上不必先背证明，先记住它可以暴露矩阵的有效秩、处理最小二乘并提供稳定的伪逆。

## 7. NumPy 实验：把公式变成输出

安装 NumPy 后运行以下代码。它依次验证范数、点积、叉积、旋转、点面距离和最小二乘平面拟合。

```python
import numpy as np

np.set_printoptions(precision=4, suppress=True)

def skew(a):
    x, y, z = a
    return np.array([[0, -z, y], [z, 0, -x], [-y, x, 0.0]])

def rot_z(angle):
    c, s = np.cos(angle), np.sin(angle)
    return np.array([[c, -s, 0], [s, c, 0], [0, 0, 1.0]])

p = np.array([3.0, 4.0, 0.0])
q = np.array([1.0, -2.0, 2.0])
print("norm(p) =", np.linalg.norm(p))
print("p dot q =", p @ q)
print("p cross q =", np.cross(p, q))
print("skew(p) @ q =", skew(p) @ q)

R = rot_z(np.deg2rad(90.0))
t = np.array([1.0, 2.0, 0.5])
p_world = R @ q + t
print("R^T R =\\n", R.T @ R)
print("transformed point =", p_world)

# 平面 z=2 的五个带噪近邻点
neighbors = np.array([
    [0.0, 0.0, 2.02], [1.0, 0.0, 1.98], [0.0, 1.0, 2.01],
    [1.0, 1.0, 2.00], [0.4, 0.7, 1.99]
])
A = np.c_[neighbors[:, 0], neighbors[:, 1], np.ones(len(neighbors))]
params, residuals, rank, singular = np.linalg.lstsq(A, neighbors[:, 2], rcond=None)
a, b, c = params
n = np.array([a, b, -1.0])
n /= np.linalg.norm(n)
d = c / np.sqrt(a*a + b*b + 1.0)
query = np.array([0.3, 0.2, 2.2])
print("plane z=ax+by+c =", params, "rank =", rank)
print("signed point-plane residual =", n @ query + d)
```

### 实验检查

1. 把旋转角改成 45°，预测变换点是否符合图形直觉。
2. 把 `neighbors[0,2]` 改成 `3.0`，观察拟合平面和残差变化。
3. 删除三个近邻，只保留共线点，观察 `rank` 和结果是否稳定。
4. 把法向量归一化代码注释掉，比较残差是否仍然是米制距离。

## 8. 常见错误与反例

### 错误一：把度数传给 `sin`

`np.sin(90)` 计算的是 90 弧度，不是 90°。这会让旋转矩阵看似有数值，实际完全错误。

### 错误二：平移和旋转顺序写反

`R @ p + t` 与 `R @ (p+t)` 不等价。前者表示先旋转再平移，后者把平移也当成了待旋转的点。

### 错误三：忽略法向量归一化

`n^T p+d` 只有在 `||n||=1` 时才等于距离。否则它只是一个比例不同的代数残差。

### 错误四：坐标系下标缺失

`t=[0.1,0,0]` 可能是 LiDAR 在 IMU 中的平移，也可能是 IMU 在世界中的位置。没有下标就没有可验证的含义。

### 错误五：用逆矩阵解决所有方程

实际代码不要写 `np.linalg.inv(A.T @ A) @ A.T @ b` 作为默认方案，接近退化时数值误差会放大。优先使用 `lstsq`、QR 或 SVD。

## 10. 参考答案

1. `sqrt(4+1+4)=3`。
2. 点积为 `2`，叉积为 `[6,-3,-4]`。
3. 旋转保持长度和夹角，列向量应正交且单位化，因此 `R^TR=I`。
4. 先 `p_I=R_L^I p_L+t_L^I`，再 `p_W=R_I^W p_I+t_I^W`。
5. 可取 `n=[0,0,1]`、`d=-2`，方程为 `z-2=0`。
6. 缺乏独立方向，参数对噪声极敏感，矩阵秩接近不足。
7. `5×1`。
8. 两向量垂直。
9. `0.4/2=0.2`。
10. `R2` 先作用。
11. 地图平面定义在世界系，残差两端必须在同一坐标系。
12. `p×v`，即叉积。
13. 一个点无法确定平面方向和偏移，至少需要足够的非共线约束。
14. 可能是反射矩阵、坐标系手性错误或数值更新损坏。
15. 先把 `p_L` 旋转并平移到 IMU 系。
16. 它综合所有点的误差，能降低随机噪声影响。
17. 该方向变化最小，通常接近平面法向；但必须结合另外两个特征值判断退化。
18. 加速度方向仍在机体系，必须先减偏置、旋转到世界系并加重力。
19. `np.allclose(R.T @ R, np.eye(3)) and np.isclose(np.linalg.det(R), 1.0)`。
20. 维度不匹配会直接暴露错误；维度正确仍需物理单位、坐标系和数值实验共同验证。

这一篇的完成标志不是背下公式，而是你能拿一张纸回答：一个点从 LiDAR 测量到地图残差，经过了哪些坐标、哪些矩阵、哪些单位。下一篇将把这些向量和矩阵放进三维旋转、外参和 SE(3) 中。
