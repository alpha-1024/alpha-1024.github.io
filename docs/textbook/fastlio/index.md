# FAST-LIO：从零基础到源码

这是一条独立于原有六册教材的学习主线，目标是让你能够从“一个激光点如何变换到地图”开始，逐步读懂 FAST-LIO2 的数学、数据流、源码和实验结果。默认读者的大学数学基础为零，因此每一章都会先解释直觉，再给出公式，最后用 NumPy 或 C++ 做可运行验证。

## 你最终要达到的能力

- 能区分 LiDAR、IMU、机体和世界坐标系，并手算 `Rp+t`。
- 能解释 IMU 的角速度、加速度、偏置、重力和离散积分。
- 能从近邻点拟合平面，计算点到平面残差并理解 Jacobian。
- 能从一维卡尔曼滤波推到 EKF、ESKF 和迭代 ESIKF。
- 能解释 SO(3)、S2、`Exp/Log`、`boxplus/boxminus` 为什么出现。
- 能沿着 FAST-LIO 的 `IMU 传播 -> 点云去畸变 -> 最近邻 -> 残差 -> 更新 -> 地图增量` 主链路调试。

## 推荐顺序

```text
数学语言与向量
  -> 矩阵、坐标变换与三维旋转
  -> 导数、偏导、Jacobian 与线性化
  -> 概率、协方差、最小二乘
  -> 一维/多维卡尔曼滤波
  -> IMU 运动模型与预积分直觉
  -> 点云、平面拟合、KD-tree 与 ICP
  -> ESKF、SO(3)、S2 与迭代更新
  -> FAST-LIO2 论文、源码和实验
```

不要跳过前两篇直接阅读 `esekfom.hpp`。如果你还不能解释 `R_I^W(R_L^I p_L+t_L^I)+t_I^W` 的每一项，后面的源码阅读会变成记忆符号。

## 学习纪律

1. 每个公式先写清楚变量、单位、维度和坐标系。
2. 每段代码都要修改至少一个输入，观察输出变化。
3. 所有实验保存参数、终端输出、轨迹图和失败原因。
4. 先用小数据验证数学，再用 rosbag 验证系统。
