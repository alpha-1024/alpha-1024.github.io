# 具身智能算法工程师教材

这套教材面向拥有一台 RTX 5090 主机、具备基础编程能力，希望进入具身智能算法岗位的学习者。教材不以“跑通官方 Demo”为目标，而以独立解释、实现、测试和改进机器人系统为目标。

## 使用规则

1. 按顺序学习，不要直接跳到 VLA。
2. 每段代码必须自己输入、运行和修改，不要只阅读。
3. 每章结束必须完成检查题，不能回答时回到对应章节。
4. 每个实验保存配置、日志、指标和失败案例。
5. 每周只推进一个主要目标，避免同时开启多个框架。

## 全书结构

### 第一册：数学与工程基础

- 向量、矩阵、坐标系与 SE(3)。
- 概率、估计、优化和神经网络基础。
- Python、NumPy、PyTorch 和可复现实验。
- Linux、Git、Docker、CMake 和现代 C++。
- ROS2 节点、通信、TF2、rosbag2 和调试。

### 第二册：视觉、点云与位姿估计

- 相机模型和标定。
- OpenCV 图像几何与 PnP。
- 深度图、点云、ICP 和 RANSAC。
- 检测、分割、深度估计和 6D Pose。
- RGB-D 目标定位综合项目。

### 第三册：SLAM、导航与感知融合

- 贝叶斯滤波、EKF/UKF、IMU 和轮速融合。
- SLAM 前端、后端、回环和图优化。
- 栅格地图、A*、代价地图和轨迹跟踪。
- Nav2 行为树与恢复策略。

### 第四册：机械臂规划与机器人控制

- 正逆运动学、雅可比和奇异性。
- 关节空间与笛卡尔轨迹。
- MoveIt2、ros2_control 和碰撞检测。
- PID、前馈、阻抗控制和模型预测控制。

### 第五册：强化学习、模仿学习与 VLA

- MDP、DQN、PPO、SAC。
- Isaac Lab 并行仿真和 Sim2Real。
- BC、DAgger、ACT、Diffusion Policy。
- Transformer、VLM、LoRA、OpenVLA 与 LeRobot。

### 第六册：CUDA、TensorRT 与工程部署

- GPU 执行模型和 CUDA 内存层次。
- PyTorch Profiler、Nsight 和性能分析。
- ONNX、TensorRT、FP16、INT8。
- 延迟、吞吐、显存、功耗和精度评估。

## 学习节奏

每周建议投入 15-20 小时：理论 4 小时、编程 8 小时、实验 4 小时、复盘 2 小时。每完成一册，至少做一个能够录像演示、能够量化评估、能够由别人复现的项目。
