# 第二册第四篇：检测、分割、深度学习与 6D 位姿

机器人视觉的最终输出通常不是一句“画面里有杯子”，而是可供规划器使用的状态：杯子属于哪个实例、位于哪个坐标系、三维位置和方向是多少、结果在什么时候有效、误差有多大、遮挡或对称性会产生哪些等价解。目标检测和分割只完成了这条链路的前半段。

本篇把学习方法与前面建立的相机几何、深度和点云方法连接起来。核心原则是：网络输出提供数据驱动的语义和对应，几何模型提供可解释约束，时间与坐标系统保证输出能被机器人消费，任务级实验决定系统是否真正可用。

## 第 1 章：先定义任务输出，再选择模型

### 1.1 五类常见视觉任务

**图像分类**给整幅图一个或多个类别，适合场景识别和状态判断，无法直接区分多个实例的位置。

**目标检测**为每个实例输出类别、置信度和矩形框。它计算高效，适合粗定位和跟踪入口，但框中包含背景，不能表达精确轮廓。

**语义分割**给每个像素一个类别，同类多个物体会合并。它适合可通行区域、地面和墙面等“stuff”类别。

**实例分割**同时区分同类实例并输出掩码，适合抓取、计数和掩码深度统计。掩码边缘和遮挡仍可能不准。

**关键点或稠密对应**输出物体上有语义的二维点，或每个可见像素对应的物体表面坐标，可进一步通过 PnP、三角化或配准恢复 6D 位姿。

6D 位姿指三个平移自由度和三个旋转自由度。对轴对称瓶子，绕对称轴旋转在视觉和任务上可能不可区分，所以“6D 真值”本身也需要等价类定义。

### 1.2 从下游误差反推输出

如果任务只需机械臂把物体推入大容器，二维框加粗深度可能足够；若要把插头插入插座，需要毫米级位置、方向、接触几何和校准；导航避障更关心连续漏检时间和障碍边界，而不是单帧类别 mAP。

选择模型前写清楚：目标坐标系、更新频率、最远和最近距离、允许位置/角度误差、遮挡范围、对象是否对称、错误结果如何降级、算力和延迟预算。没有这些约束，模型比较会退化为排行榜复述。

## 第 2 章：数据集是测量协议

### 2.1 样本独立性与划分

机器人视频相邻帧高度相似，不能随机按图片划分。根据目标泛化能力，至少按以下实体之一隔离：采集序列、物体实例、房间、光照日期、相机或机器人。若要测试新实例泛化，同一个实体不能同时出现在训练和测试；若只要求已知实例定位，则可以共享实体但必须隔离轨迹和背景。

验证集用于模型与阈值选择，测试集只用于最终报告。反复查看测试集失败并据此改模型，测试集事实上已经变成验证集，需要新建真正独立的测试集。

### 2.2 标注规范必须处理歧义

检测框应规定截断物体是否标注、遮挡超过多少比例忽略、小物体最小像素、透明区域是否属于实例。实例掩码应规定孔洞、反射、阴影和被遮挡区域的处理。关键点应区分“不可见但可推断”和“被遮挡无法观测”。

位姿标注还必须规定物体坐标系。建议把原点放在稳定可复现的 CAD 位置，轴方向遵循右手系，并保存从模型坐标到实际物体坐标的尺度。网格以毫米建模却按米加载会造成千倍平移错误。

### 2.3 数据清单与自动检查

```python
from dataclasses import dataclass
from pathlib import Path
import json
import numpy as np

@dataclass(frozen=True)
class DatasetIssue:
    sample_id: str
    field: str
    message: str

def validate_detection_record(record, image_width, image_height):
    issues = []
    sample_id = str(record.get("id", "unknown"))
    for index, annotation in enumerate(record.get("annotations", [])):
        box = np.asarray(annotation.get("bbox_xyxy", []), dtype=float)
        field = f"annotations[{index}].bbox_xyxy"
        if box.shape != (4,) or not np.isfinite(box).all():
            issues.append(DatasetIssue(sample_id, field, "box must contain 4 finite values"))
            continue
        x1, y1, x2, y2 = box
        if not (0 <= x1 < x2 <= image_width and 0 <= y1 < y2 <= image_height):
            issues.append(DatasetIssue(sample_id, field, "box outside image or non-positive"))
        if "category_id" not in annotation:
            issues.append(DatasetIssue(sample_id, f"annotations[{index}]", "missing category"))
    return issues
```

检查还应覆盖图片是否存在、尺寸是否与元数据一致、掩码面积与框是否匹配、类别 ID 是否在字典内、关键点可见性是否合法、位姿矩阵是否为 $SE(3)$、相机内参与图片分辨率是否匹配、同一文件是否出现在多个划分。

### 2.4 标注一致性比数量更重要

抽取一部分样本让两名标注者独立标注，计算框 IoU、掩码 IoU、关键点像素距离和姿态差异。若人之间分歧已经超过任务容许误差，模型不可能从不一致目标中学到稳定定义。先修规范和工具，再扩大数据量。

## 第 3 章：目标检测的核心结构

### 3.1 从图像到多尺度特征

骨干网络把图像变成不同分辨率的特征图。浅层保留高分辨率边缘，深层具有更强语义但空间更粗。特征金字塔融合多个尺度，使小目标能使用高分辨率特征，大目标使用更大感受野。

检测器大致分为两阶段与单阶段。两阶段方法先生成候选区域，再分类和回归，通常易于获得高精度；单阶段方法直接在密集位置预测类别和框，适合低延迟。现代架构边界已不绝对，应基于目标平台实测。

### 3.2 框参数与 IoU

矩形框可用 $(x_1,y_1,x_2,y_2)$、中心宽高或相对网格偏移表示。任何数据转换都要明确边界是闭区间还是半开区间、坐标是否归一化、resize 是否保持宽高比以及 padding 偏移。

交并比定义为

$$
\operatorname{IoU}(A,B)=\frac{|A\cap B|}{|A\cup B|}.
$$

IoU 对大框和小框的像素偏移敏感度不同。一个 4 px 偏差对 20 px 小目标可能严重，对 500 px 大目标影响很小，因此应按目标尺寸切片评价。

### 3.3 分类、定位与正负样本

检测损失通常包含分类损失、框回归损失和可能的目标存在性损失。前景远少于背景会导致类别不平衡，可使用采样、类别权重或 focal loss。框回归可使用 L1、Smooth L1、IoU/GIoU/DIoU 类损失。

训练损失的权重不是无意义超参数。分类损失过强可能类别准但框不准，框损失过强可能破坏置信度排序。应分别记录每项损失、梯度规模和验证指标。

### 3.4 非极大值抑制

同一物体周围会产生多个候选框。NMS 按分数选择最高框，删除与其 IoU 超过阈值的同类框，再继续处理。密集相邻物体可能被错误合并；阈值过高则重复框保留。

```python
def box_iou_one_to_many(box, boxes):
    top_left = np.maximum(box[:2], boxes[:, :2])
    bottom_right = np.minimum(box[2:], boxes[:, 2:])
    wh = np.maximum(0.0, bottom_right - top_left)
    intersection = wh[:, 0] * wh[:, 1]
    area_a = max(0.0, box[2] - box[0]) * max(0.0, box[3] - box[1])
    area_b = np.maximum(0.0, boxes[:, 2] - boxes[:, 0]) * np.maximum(
        0.0, boxes[:, 3] - boxes[:, 1]
    )
    return intersection / np.maximum(area_a + area_b - intersection, 1e-12)

def nms(boxes, scores, iou_threshold=0.5):
    boxes = np.asarray(boxes, dtype=np.float64)
    scores = np.asarray(scores, dtype=np.float64)
    if boxes.ndim != 2 or boxes.shape[1] != 4 or len(boxes) != len(scores):
        raise ValueError("boxes must be [N,4] and scores [N]")
    order = np.argsort(scores)[::-1]
    keep = []
    while order.size:
        current = int(order[0])
        keep.append(current)
        if order.size == 1:
            break
        remaining = order[1:]
        overlap = box_iou_one_to_many(boxes[current], boxes[remaining])
        order = remaining[overlap <= iou_threshold]
    return keep
```

生产代码应使用框架优化算子；教学实现用于理解边界行为。测试必须包含空输入、完全重合、完全分离、相切、相同分数、非法框和类别隔离。

## 第 4 章：检测指标与置信度

### 4.1 Precision、Recall 与 AP

固定 IoU 和分数阈值后，预测与真值一对一匹配，得到 TP、FP、FN：

$$
\operatorname{Precision}=\frac{TP}{TP+FP},\qquad
\operatorname{Recall}=\frac{TP}{TP+FN}.
$$

改变分数阈值得到 precision-recall 曲线，曲线下面积形成 AP。mAP 对类别取平均，可能让稀有关键类别被普通类别掩盖。报告必须注明 IoU 范围、类别平均方式和实现版本。

### 4.2 机器人更关心连续失败

单帧召回率 99% 不代表控制安全。若漏检集中成连续 10 帧，在 30 Hz 下相当于 333 ms 失明。应统计最长连续漏检、每小时误报、目标首次出现到稳定检测的时间、轨迹中断次数和端到端消息年龄。

### 4.3 置信度不是正确概率

神经网络的 0.9 分数不一定表示 90% 正确。通过可靠性图和 Expected Calibration Error 可以检查校准；温度缩放可在独立验证集上调整分类 logits。但分布变化后校准仍可能失效，系统还要监控输入分布、图像质量和未知类别。

## 第 5 章：语义与实例分割

### 5.1 像素级损失

语义分割常用交叉熵、Dice 或 focal 类损失。类别极不平衡时，仅使用像素准确率会被大面积背景支配。例如背景占 98%，永远预测背景也有 98% 准确率，却对机器人毫无价值。

Dice 系数为

$$
\operatorname{Dice}=\frac{2|P\cap G|}{|P|+|G|}.
$$

IoU 与 Dice 都关注区域重合，但对边界精度不敏感。插接、抓取薄物体时还应报告边界 F-score 或轮廓距离。

### 5.2 掩码转三维时的边缘污染

把实例掩码直接用于深度统计时，预测边缘可能混入背景。可对掩码做小范围腐蚀，或根据深度连通性和中位数剔除边缘飞点。腐蚀会损失小物体，因此结构元素大小应相对目标尺寸设置。

```python
import cv2

def robust_mask_depth(depth_m, mask, min_depth=0.1, max_depth=5.0):
    binary = (mask > 0).astype(np.uint8)
    area = int(binary.sum())
    if area == 0:
        return None
    radius = 1 if area < 2500 else 2
    kernel = np.ones((2 * radius + 1, 2 * radius + 1), np.uint8)
    inner = cv2.erode(binary, kernel, iterations=1).astype(bool)
    values = depth_m[inner]
    valid = values[np.isfinite(values) & (values >= min_depth) & (values <= max_depth)]
    if valid.size < 20:
        return None
    median = float(np.median(valid))
    mad = float(np.median(np.abs(valid - median)))
    scale = max(1.4826 * mad, 1e-3)
    inliers = valid[np.abs(valid - median) < 3.0 * scale]
    if inliers.size < 20:
        return None
    return {
        "depth_m": float(np.median(inliers)),
        "mad_m": mad,
        "valid_count": int(inliers.size),
        "valid_ratio": float(inliers.size / max(area, 1)),
    }
```

中位数深度只能给粗三维中心，不能给完整方向。细长或倾斜物体的框中心射线也未必穿过几何中心，需要点云、关键点或 CAD 配准。

## 第 6 章：训练一个可信的分割模型

### 6.1 预处理必须成对作用

随机裁剪、翻转、旋转和 resize 必须同时作用于图像、框、掩码、关键点和相机内参。只增强图像会让标签错位；对带位姿的样本做水平翻转还会改变物体与相机坐标的几何关系，不能沿用原姿态。

颜色增强可模拟曝光和白平衡变化，但不应破坏必须保留的物理线索。深度噪声增强应依据真实设备的距离和边缘噪声，而不是只加固定高斯噪声。

### 6.2 最小训练循环应记录什么

除了总 loss，还要记录每项损失、学习率、梯度范数、每秒样本数、GPU 显存、训练与验证 IoU、按类别和尺寸切片指标。保存最佳验证模型和最后模型，checkpoint 中包含类别映射、预处理配置和 Git commit。

在 RTX 5090 上可以使用 AMP、较大 batch、编译优化和多进程数据加载，但先完成三个正确性检查：单样本前向和标签对齐可视化；小数据集过拟合；关闭增强后的确定性回放。GPU 利用率低不一定是错误，小模型可能由数据或 CPU 后处理限制。

### 6.3 数据增强的反例

为了增加多样性，把物体随机粘贴到背景上可能提升检测 mAP，却破坏接触阴影、遮挡关系和深度一致性。模型可能学到剪贴边缘，上真实机器人后失败。合成数据应通过域随机化、物理渲染和真实小规模验证形成证据链，不是越随机越好。

## 第 7 章：单目深度估计

### 7.1 相对深度与度量深度

单幅图像本身缺少绝对尺度。网络可以从训练数据中的物体大小、透视和纹理学习统计先验，输出看似米制深度，但换相机、场景或物体尺度后可能失效。必须区分只保证远近顺序的相对深度和以米为单位的度量深度。

单目深度常见损失包括对数深度、尺度不变损失、梯度或法线损失。直接在深度 $Z$ 上做 L1 会让远处大数值主导，逆深度 $1/Z$ 更强调近处，但任务权重也会改变。

### 7.2 评价指标

常用绝对相对误差

$$
\operatorname{AbsRel}=\frac1N\sum_i\frac{|\hat Z_i-Z_i|}{Z_i},
$$

以及 RMSE、对数误差和阈值准确率。评价前必须说明是否对预测做尺度/偏移对齐；经过真值中位数对齐的相对深度不能宣称具备绝对米制精度。

### 7.3 机器人使用时的保护

单目深度适合提供结构先验、补充稀疏深度或做相对排序。若直接用于碰撞和抓取，应在目标场景用真实测量校准尺度，输出不确定性，并与已知地面、物体尺寸、双目或雷达交叉检查。面对镜子，模型可能预测镜中空间而不是镜面位置，这对避障十分危险。

## 第 8 章：从二维关键点到 PnP

### 8.1 对应关系定义

已知物体模型上的三维点 $P_i$ 和图像关键点 $p_i$，PnP 求物体到相机的位姿：

$$
s_i\tilde p_i=K(RP_i+t).
$$

输入三维点定义在 object frame，OpenCV `solvePnP` 返回的通常是把 object frame 点变到 camera frame 的 $R,t$，即 ${}^cT_o$。机器人常需要 ${}^bT_o={}^bT_c{}^cT_o$。矩阵连乘方向必须通过已知点验证。

### 8.2 点的空间分布

理论最少点数不等于工程足够。关键点集中在小区域时，少量像素误差会放大姿态误差；共线点退化；平面点可能出现多解。应让关键点覆盖物体外形和深度变化，并输出每点可见性或置信度。

### 8.3 PnP + RANSAC 完整包装

```python
from dataclasses import dataclass
import cv2
import numpy as np

@dataclass
class PoseEstimate:
    success: bool
    reason: str
    transform_camera_object: np.ndarray | None = None
    inlier_indices: np.ndarray | None = None
    reprojection_rmse_px: float | None = None

def estimate_pose_pnp(object_points, image_points, K, dist,
                      reprojection_threshold_px=3.0):
    object_points = np.asarray(object_points, np.float64).reshape(-1, 3)
    image_points = np.asarray(image_points, np.float64).reshape(-1, 2)
    if len(object_points) != len(image_points) or len(object_points) < 6:
        return PoseEstimate(False, "need at least six paired points")
    if not np.isfinite(object_points).all() or not np.isfinite(image_points).all():
        return PoseEstimate(False, "non-finite correspondence")

    ok, rvec, tvec, inliers = cv2.solvePnPRansac(
        object_points, image_points, K, dist,
        iterationsCount=200,
        reprojectionError=reprojection_threshold_px,
        confidence=0.999,
        flags=cv2.SOLVEPNP_EPNP,
    )
    if not ok or inliers is None or len(inliers) < 6:
        return PoseEstimate(False, "RANSAC did not find enough inliers")
    indices = inliers.reshape(-1)
    ok, rvec, tvec = cv2.solvePnP(
        object_points[indices], image_points[indices], K, dist,
        rvec, tvec, useExtrinsicGuess=True, flags=cv2.SOLVEPNP_ITERATIVE,
    )
    if not ok:
        return PoseEstimate(False, "nonlinear pose refinement failed")
    projected, _ = cv2.projectPoints(object_points[indices], rvec, tvec, K, dist)
    residual = projected.reshape(-1, 2) - image_points[indices]
    rmse = float(np.sqrt(np.mean(np.sum(residual ** 2, axis=1))))
    R, _ = cv2.Rodrigues(rvec)
    T = np.eye(4)
    T[:3, :3] = R
    T[:3, 3] = tvec.reshape(3)
    if T[2, 3] <= 0:
        return PoseEstimate(False, "object origin lies behind camera")
    return PoseEstimate(True, "ok", T, indices, rmse)
```

进一步检查包括内点空间覆盖、每点残差、物体是否完全在合理深度、位姿是否违反工作空间、轮廓渲染是否与观测一致，以及与上一帧运动是否一致。低重投影误差不保证物体坐标系或模型尺寸正确。

## 第 9 章：6D 位姿估计的主要路线

### 9.1 关键点 + PnP

网络预测预定义语义关键点及置信度，PnP 恢复位姿。优点是几何可解释、能使用 RANSAC；缺点是遮挡关键点难预测，对对称物体关键点定义可能不唯一。

### 9.2 稠密对象坐标

网络为每个目标像素预测其在物体模型坐标中的三维位置，形成大量 2D-3D 对应，再用 PnP/RANSAC。稠密对应对局部遮挡较鲁棒，但标签生成、坐标归一化和对称性处理更复杂。

### 9.3 直接位姿回归

网络直接输出平移和旋转参数，推理简单，但旋转表示、尺度、数据覆盖和不确定性较难处理。它仍应通过渲染和几何残差验证，不能因为输出维度是 6 或 7 就认为结果符合 $SE(3)$。

### 9.4 RGB-D 粗到精

先用检测/分割得到实例和粗位姿，再从掩码深度生成物体点云，与 CAD 模型做 ICP 或渲染优化。深度能提供米制尺度和表面约束，但透明、反光、遮挡以及错误掩码会污染点云。合理系统会让学习模型提供捕获范围内初值，让几何精化提供可解释残差。

### 9.5 基于模板或渲染比较

对已知 CAD 模型从大量视角渲染模板，与输入特征比较得到姿态。它适合已知对象，但模板离散、材质和光照域差异会影响表现。现代方法可在特征空间对齐或通过可微渲染优化。

## 第 10 章：旋转表示

### 10.1 四元数

单位四元数连续表示旋转，但 $q$ 与 $-q$ 表示同一姿态。训练损失若直接做欧氏距离，应考虑符号等价，例如取 $\min(\|q-\hat q\|,\|q+\hat q\|)$，并在输出后归一化。单位范数约束和双覆盖仍会给优化带来问题。

### 10.2 欧拉角

欧拉角直观，但存在万向锁、周期边界和旋转顺序歧义。预测 179 度与 -179 度在数值上差 358 度，物理上只差 2 度。不推荐作为通用网络回归目标。

### 10.3 旋转矩阵与连续 6D 表示

直接预测 9 个数需要投影到 $SO(3)$。一种连续 6D 表示预测两个三维向量，通过 Gram-Schmidt 得到旋转矩阵前两列，再叉乘得到第三列。它避免了部分不连续，但仍需检查输入向量近共线的数值退化。

评价旋转时使用测地角：

$$
e_R=\arccos\left(\operatorname{clip}\left(
\frac{\operatorname{trace}(R_{gt}^TR_{pred})-1}{2},-1,1\right)\right).
$$

clip 防止浮点误差让 `arccos` 输入略超范围。

## 第 11 章：对称物体和可见性

### 11.1 离散与连续对称

立方体可能有多个离散等价旋转，圆柱可能绕轴连续对称。标注时若随机选择某个等价姿态，网络会面对互相矛盾的监督。可以定义规范姿态、预测对称不变表示、在损失中对等价变换取最小值，或输出多假设。

### 11.2 任务对称性不同于几何对称性

没有纹理的杯子主体近似轴对称，但杯把打破对称；瓶盖外形对称，标签文字可能提供方向；抓取任务可能不关心绕竖轴角度，倾倒任务却关心开口或把手方向。评价对称群必须由可观测外观和下游任务共同定义。

### 11.3 遮挡下的多解

只看到物体一小部分时，多种完整姿态可能产生相同可见区域。强行输出单个高置信位姿会低估不确定性。可输出候选集合、分布或明确 `ambiguous` 状态，并让规划器选择信息增益视角。

## 第 12 章：位姿评价指标

### 12.1 平移和旋转误差

分别报告厘米和角度直观，但不能完整表示模型表面错位。远离旋转中心的点会因小角度产生较大位置误差。

### 12.2 ADD 与 ADD-S

对模型点集 $\mathcal M$，ADD 为

$$
\operatorname{ADD}=\frac1{|\mathcal M|}\sum_{x\in\mathcal M}
\|(R_{pred}x+t_{pred})-(R_{gt}x+t_{gt})\|.
$$

对称物体常使用最近点版本 ADD-S：

$$
\operatorname{ADD-S}=\frac1{|\mathcal M|}\sum_{x_1\in\mathcal M}
\min_{x_2\in\mathcal M}
\|T_{pred}x_1-T_{gt}x_2\|.
$$

ADD-S 可能让非对称局部结构被错误忽略，因此应使用真实对称定义，而不是所有物体都用最近点。

### 12.3 投影误差和可见表面

二维投影误差衡量模型点投影差异，适合 AR 对齐，但远距离时较大的三维误差也可能只产生少量像素误差。VSD 类指标考虑可见表面差异，更适合遮挡场景。报告应组合指标，并以抓取或插接成功率作最终验证。

### 12.4 阈值曲线

不要只报告“ADD 小于物体直径 10% 的准确率”。绘制不同误差阈值下的召回曲线或 AUC，按物体、距离、遮挡和对称类别切片。大物体用直径归一化可能得到宽松的绝对误差，任务仍可能失败。

## 第 13 章：不确定性与质量门禁

### 13.1 误差来源分解

位姿误差来自图像噪声、关键点或掩码误差、相机内参、模型尺寸、外参、时间同步和算法退化。仅让网络输出一个方差无法覆盖系统误差。应把可标定误差、统计测量噪声和分布外风险分别管理。

### 13.2 PnP 的局部协方差

在最优位姿附近，重投影残差对位姿增量的雅可比为 $J$，若像素噪声协方差为 $\Sigma_p$，近似位姿协方差可由

$$
\Sigma_\xi\approx(J^T\Sigma_p^{-1}J)^{-1}
$$

得到。它反映关键点几何和像素噪声下的局部可观性，不包含错误对应和模型偏差。矩阵条件数过大时应拒绝结果，而不是报告巨大但仍“有效”的协方差。

### 13.3 门禁条件

可组合以下证据：检测/分割置信度、有效深度比例、PnP 内点数和覆盖、重投影 P95、正深度、轮廓 IoU、点云配准残差、位姿跳变量、输入图像质量和是否超出工作空间。任一硬安全条件失败就输出无效；软质量可形成分级状态。

阈值必须在验证集上选择并在独立测试集报告，不能逐个失败样本手工调到通过。

## 第 14 章：时间跟踪与滤波

### 14.1 滤波不能修复系统偏差

低通、卡尔曼或指数平滑可以降低零均值抖动，但相机外参错误、尺度错误和时间延迟会形成偏差。过强滤波还增加控制延迟。先分析频谱和误差来源，再选择滤波带宽。

### 14.2 数据关联

多实例跟踪需要把当前检测与历史轨迹关联。可以组合框 IoU、三维距离、外观描述和运动预测。只按最近三维中心关联，在物体交叉或深度跳变时会交换 ID。

### 14.3 丢失与重初始化

短暂漏检可用运动模型预测，但预测时间越长不确定性越大。超过门槛应将轨迹置为 lost，重新检测后谨慎关联。不能无限发布预测姿态并保留原置信度。

## 第 15 章：ROS2 端到端位姿节点

### 15.1 数据流

```text
RGB + Depth + CameraInfo
  -> 时间与分辨率检查
  -> 检测/实例分割
  -> 关键点或掩码内三维点
  -> PnP / RGB-D 粗位姿
  -> 几何精化与质量门禁
  -> 查询采样时刻 TF
  -> PoseWithCovarianceStamped + diagnostics
```

输出消息必须使用采样时间戳，而不是算法完成时间；`frame_id` 必须与数值坐标一致。处理延迟另存在诊断字段，方便消费者判断消息年龄。

### 15.2 并发和背压

若网络推理 50 ms 而输入 30 Hz，无限制队列会越来越旧。使用深度 1 的队列保留最新帧，或在工作线程忙时替换待处理帧。模型初始化和 GPU 上下文创建只做一次。回调线程与推理线程共享数据时使用明确所有权，避免输入缓冲被覆盖。

### 15.3 生命周期与模型版本

生命周期节点在 configure 阶段加载模型和参数，在 activate 后才订阅与发布；加载失败时不进入 active。诊断输出模型哈希、类别表、内参/外参版本和推理后端。热切换模型必须经过兼容性检查，不能只替换权重文件。

## 第 16 章：完整 RGB-D 6D 位姿实验

### 16.1 目标

选择 3 至 5 个刚性物体，至少包含一个纹理丰富非对称物体、一个弱纹理物体和一个对称物体。输入 RGB-D，输出 `base_link` 中位姿和置信度，用机械臂执行接近但不接触的指向动作，最后再进行低速抓取验证。

### 16.2 数据采集

按物体实例、背景、距离、视角、光照和遮挡建立采集矩阵。训练和测试场景物理隔离。保存原始 RGB、深度、内参、RGB-D 外参、机器人 TF、时间戳和 CAD 版本。使用 AprilTag、标定机械结构或高精度测量系统建立独立真值，不以算法自身输出作真值。

### 16.3 分阶段验收

第一阶段只评检测和掩码；第二阶段离线评相机坐标位姿；第三阶段检查 TF 转换后的 base 位姿；第四阶段让机械臂在安全高度指向目标；第五阶段才低速抓取。每一级都设置停止条件和回滚版本。

### 16.4 报告表

| 维度 | 最低报告内容 |
| --- | --- |
| 二维 | 每类 AP、掩码 IoU、连续漏检 |
| 位姿 | 平移、旋转、ADD/ADD-S 阈值曲线 |
| 切片 | 距离、遮挡、光照、实例、对称性 |
| 时序 | 采集到输出 P50/P95/P99、消息年龄 |
| 质量 | 拒绝率、错误接受率、校准曲线 |
| 任务 | 指向误差、抓取成功率、碰撞/急停 |
| 资源 | GPU/CPU、显存、温度、连续运行时间 |

错误接受比主动拒绝更危险。系统在困难场景输出“未知”可以触发重新观察；自信地发布错误位姿可能造成碰撞。

## 第 17 章：五个失败案例

### 案例一：二维框准确，三维中心落在背景

框中心不一定在物体内部，深度还可能是孔洞。改用实例掩码和稳健深度统计，检查有效比例；对于环形或细长物体，使用表面点云和模型几何而不是单像素。

### 案例二：重投影很好，机械臂仍偏 4 厘米

PnP 可以在错误 CAD 尺度或错误相机外参下获得低像素残差。逐层验证相机坐标位姿、模型尺寸、手眼外参、TF 方向和时间同步。用固定三维标记区分视觉内误差和 camera-to-base 误差。

### 案例三：对称瓶子角度随机跳变

单帧对绕轴角度不可观，网络或 PnP 在等价解之间切换。按任务定义忽略对称轴角度、输出等价类，或用标签纹理、瓶盖特征和时间连续性打破对称。不能仅用平滑隐藏不可观性。

### 案例四：仿真准确率高，真实透明物体失败

渲染图拥有干净深度和理想材质，真实深度相机对透明表面产生孔洞和背景深度。仿真必须模拟传感器缺失机制，并加入真实数据微调；安全系统对低有效深度主动拒绝，可切换多视角或其他传感器。

### 案例五：模型推理 12 ms，系统延迟却 180 ms

分别测量图像传输、同步等待、预处理、主机到 GPU、推理、NMS、点云、TF 等待和发布。检查 CUDA 异步计时是否同步、ROS 队列是否积压、第一次推理是否包含初始化。优化最长路径和 P95，而不是只展示网络 kernel 时间。

## 第 19 章：参考答案

### 一、理论题答案

1. 检测给类别和粗矩形，不能精确排除背景；语义分割给每像素类别但不分同类实例；实例分割给独立轮廓，适合掩码深度与点云；关键点建立物体模型语义点到图像点的对应，可经 PnP 求完整位姿。选择取决于下游所需几何。

2. 相邻帧的背景、物体姿态和噪声几乎相同，训练集和测试集共享近重复信息，指标高估对新轨迹和场景的泛化。应按序列、实例或场景划分。

3. 分数由训练目标和数据分布产生，神经网络常过度自信。只有在独立同分布验证集上通过可靠性图等校准后才近似概率，分布变化时仍可能失效。

4. 单目观测缺少绝对尺度，网络米制输出依赖训练分布先验。换相机、物体尺度或场景后可能整体缩放错误，避障需要真实度量校准、其他尺度来源和不确定性保护。

5. 根据接口定义，物体三维点在 object frame、像素在 camera image，OpenCV 通常返回 ${}^cT_o$。用已知模型点经输出变换和内参重投影检查；再与 TF 按上下标方向连乘，不能只根据变量名猜。

6. 多个旋转产生相同外观或任务状态，任意选择单一真值会形成矛盾监督，普通角度误差也会惩罚物理等价预测。应定义对称群，在损失和评价中对等价姿态取最小，或输出多假设。

### 二、代码题答案

NMS 测试包括：空输入；单框；完全分离全部保留；完全重合只保留最高分；相切 IoU 为零；IoU 恰在阈值的边界语义；相同分数的确定性；非法负面积框；分数长度不匹配；不同类别应分别运行 NMS。写出具体断言且覆盖八类即可满分。

门禁输入应包含位姿矩阵、检测/掩码分数、有效深度比例、PnP 内点和覆盖、重投影统计、协方差或条件数、工作空间、时间戳年龄、与上一帧差异。输出不是简单 bool，而是 `valid`、质量等级、标准化拒绝码和诊断数值。拒绝原因包括非有限、非 $SE(3)$、深度不足、几何退化、残差超限、越界、过期和跳变。

如果关键点来自已经去畸变的图像，坐标符合 `new_K` 和零畸变，再传原 `dist` 会二次校正。正确方案是原图关键点配原 `K,dist`，或去畸变图关键点配生成图像的 `new_K` 和零畸变。

### 三、综合题答案

mAP 只评价二维检测，缺少实例分割质量、深度有效率、相机坐标位姿、TF/手眼误差、对称性、时序、失败拒绝和抓取结果。验证链应从独立场景二维指标开始，进入带真值离线位姿指标，按距离/遮挡/光照切片；再做 rosbag 部署路径回放，测端到端 P95/P99；随后在仿真和固定工装验证坐标系、门禁和急停；实机先高处指向、低速空抓，最后逐级抓取。每级设置通过阈值、停止条件和旧版本回滚。

对称杯子的输出应包含两个候选或绕对称轴的不确定分布、各候选权重、共同可确定的平移和轴方向，以及 `ambiguous` 标志。规划器先检查两种候选是否对应同一安全抓取；若都安全可选择对称不变抓法，否则移动相机获取能看到杯把或纹理的新视角，再更新候选。不能用上一帧平滑武断选择而不传播不确定性。
