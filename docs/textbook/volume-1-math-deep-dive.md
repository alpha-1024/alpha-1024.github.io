# 第一册扩展：机器人数学与优化详解

## 第 1 章：标量、向量、矩阵和张量

### 1.1 数学对象必须带语义

标量只有大小，例如温度、损失、时间；向量既包含多个数，也通常表示几何或状态；矩阵可以表示线性变换、数据集合、协方差或雅可比；张量是更高维数组，在深度学习中常用于批次、通道和空间维度。

同一个形状不代表同一个含义。长度为 3 的数组可能是位置、欧拉角、速度、颜色或力。工程接口必须同时说明：

- 形状。
- 数据类型。
- 单位。
- 坐标系。
- 时间戳。
- 合法范围。

例如 `position: [1, 2, 3]` 是不完整接口；`position_m_in_base_link_at_stamp` 才接近可用语义。

### 1.2 列向量与行向量

本教材默认几何向量为列向量：

$$x=\begin{bmatrix}x_1\\x_2\\x_3\end{bmatrix}$$

线性变换写成 $y=Ax$。部分图形学库使用行向量 $y=xA$，组合顺序会相反。复制代码时必须确认约定，不能只看矩阵数字。

### 1.3 范数

$$\|x\|_1=\sum_i|x_i|$$

$$\|x\|_2=\sqrt{\sum_ix_i^2}$$

$$\|x\|_\infty=\max_i|x_i|$$

$L_2$ 常表示欧氏距离；$L_1$ 对离群值相对不敏感并倾向稀疏；$L_\infty$ 约束最大单维误差。轨迹优化中“最小平均误差”和“限制任何关节最大误差”对应不同范数。

### 1.4 内积与投影

向量 $a$ 在单位方向 $n$ 上的标量投影：

$$s=n^Ta$$

向量投影：

$$a_\parallel=(n^Ta)n$$

垂直分量：

$$a_\perp=a-a_\parallel$$

点到平面距离、速度分解、接触法向力都依赖投影。

```python
import numpy as np

a = np.array([2.0, 1.0, 3.0])
n = np.array([0.0, 0.0, 1.0])
n = n / np.linalg.norm(n)
parallel = np.dot(n, a) * n
perpendicular = a - parallel
assert np.isclose(np.dot(perpendicular, n), 0.0)
```

## 第 2 章：线性方程与矩阵性质

### 2.1 线性方程组

$$Ax=b$$

可能有唯一解、无解或无穷多解。若 $A$ 是方阵且满秩，存在唯一解。数值计算中不要显式求逆再乘：

```python
x = np.linalg.solve(A, b)
```

比 `np.linalg.inv(A) @ b` 更稳定高效。

### 2.2 秩

矩阵秩是线性独立行或列的数量。机器人雅可比降秩意味着末端某些方向无法由关节速度产生，即奇异性。数据矩阵低秩可能意味着特征冗余或样本只覆盖低维流形。

### 2.3 条件数

$$\kappa(A)=\|A\|\|A^{-1}\|$$

条件数大表示输入小扰动可能造成解的大变化。IK 靠近奇异位形、标定点分布退化、PnP 点近共线时都可能出现病态矩阵。

```python
condition = np.linalg.cond(A)
if condition > 1e8:
    print('warning: ill-conditioned system')
```

阈值依赖数据尺度和精度，不能机械套用。

### 2.4 正定矩阵

对任意非零 $x$：

$$x^TAx>0$$

则 $A$ 正定。协方差至少半正定；二次损失 Hessian 正定意味着局部严格凸。由于浮点误差，理论正定矩阵可能出现极小负特征值，可用对称化和小对角正则处理，但应先排除建模错误。

## 第 3 章：特征值与矩阵分解

### 3.1 特征值

$$Av=\lambda v$$

变换后方向 $v$ 不变，只按 $\lambda$ 缩放。协方差矩阵的特征向量给出不确定性主方向，特征值给出对应方差。

二维点云协方差：最大特征向量沿点云主方向，最小特征向量可表示线法向。在三维局部点云中，最小特征向量常用于估计表面法线。

### 3.2 SVD

$$A=U\Sigma V^T$$

SVD 适用于任意矩阵。奇异值反映不同方向的缩放。用途：

- 伪逆。
- 最小二乘。
- 点云刚体配准。
- PCA。
- 判断矩阵秩和条件数。

伪逆：

$$A^+=V\Sigma^+U^T$$

很小奇异值求倒数会放大噪声，因此需要截断或阻尼。

### 3.3 PCA

数据中心化后计算协方差并做特征分解。PCA 找最大方差方向，不一定是任务最有信息的方向；未经标准化时，大单位维度会主导结果。

### 3.4 刚体配准中的 SVD

给对应点 $p_i,q_i$，先减去质心，构造：

$$H=\sum_i(p_i-\bar p)(q_i-\bar q)^T$$

对 $H=U\Sigma V^T$，旋转可由 $R=VU^T$ 得到。若 $\det(R)<0$，需处理反射。平移：

$$t=\bar q-R\bar p$$

这个方法要求对应点正确。离群对应会破坏结果，所以工程上结合 RANSAC 或鲁棒损失。

## 第 4 章：微积分与雅可比

### 4.1 导数是局部变化率

一阶泰勒展开：

$$f(x+\Delta x)\approx f(x)+J(x)\Delta x$$

多维函数 $f:\mathbb R^n\to\mathbb R^m$ 的雅可比 $J\in\mathbb R^{m\times n}$。每行对应一个输出对所有输入的偏导。

### 4.2 链式法则

若 $y=f(x),z=g(y)$：

$$\frac{\partial z}{\partial x}=\frac{\partial z}{\partial y}\frac{\partial y}{\partial x}$$

反向传播就是在计算图上反向应用链式法则。

### 4.3 梯度、Jacobian、Hessian

- 标量对向量求导得到梯度。
- 向量对向量求导得到 Jacobian。
- 标量函数二阶导组成 Hessian。

若 Hessian 在某区域正定，函数局部凸；存在负特征值时可能处于鞍点。

### 4.4 数值微分

前向差分误差 $O(h)$：

$$f'(x)\approx\frac{f(x+h)-f(x)}h$$

中心差分误差 $O(h^2)$：

$$f'(x)\approx\frac{f(x+h)-f(x-h)}{2h}$$

$h$ 太大截断误差大，太小会受浮点消减误差。梯度检查常用 $10^{-4}$ 到 $10^{-6}$，但应根据尺度选择。

## 第 5 章：二维和三维旋转

### 5.1 旋转不是普通向量

旋转矩阵属于 SO(3)：

$$SO(3)=\{R\in\mathbb R^{3\times3}|R^TR=I,\det R=1\}$$

两个旋转相乘仍是旋转，但旋转加法一般不是旋转。SO(3) 是流形和群，不是普通欧氏向量空间。

### 5.2 主动与被动旋转

主动旋转：在固定坐标系中旋转向量。被动旋转：向量不动，改变描述坐标系。两者矩阵互为逆/转置。很多“方向相反”错误来自混淆二者。

### 5.3 欧拉角

欧拉角需要旋转顺序。ZYX yaw-pitch-roll：

$$R=R_z(\psi)R_y(\theta)R_x(\phi)$$

外旋/内旋、左乘/右乘、顺序不同会得到不同结果。欧拉角适合人类展示，不适合全局优化和插值。

### 5.4 轴角与 Rodrigues

旋转由单位轴 $\omega$ 和角度 $\theta$ 表示。反对称矩阵：

$$
[\omega]_\times=
\begin{bmatrix}
0&-\omega_z&\omega_y\\
\omega_z&0&-\omega_x\\
-\omega_y&\omega_x&0
\end{bmatrix}
$$

Rodrigues：

$$R=I+\sin\theta[\omega]_\times+(1-\cos\theta)[\omega]_\times^2$$

### 5.5 四元数

单位四元数：

$$q=[w,x,y,z]^T,\quad \|q\|=1$$

组合旋转使用四元数乘法，不是逐元素相乘。$q$ 和 $-q$ 表示相同旋转，轨迹插值前应处理符号连续性，否则会走长路径。

## 第 6 章：李群与李代数

### 6.1 为什么需要李代数

旋转矩阵有 9 个元素但只有 3 个自由度，直接把矩阵元素作为优化变量会破坏正交约束。李代数提供局部最小参数扰动。

SO(3) 的李代数 $\mathfrak{so}(3)$ 可由三维向量对应的反对称矩阵表示。指数映射：

$$R=\operatorname{Exp}(\phi^\wedge)$$

对数映射把旋转映回局部向量：

$$\phi=\operatorname{Log}(R)^\vee$$

### 6.2 SE(3)

$$SE(3)=\left\{\begin{bmatrix}R&t\\0&1\end{bmatrix}\right\}$$

其李代数向量常写为 $\xi=[\rho,\phi]^T\in\mathbb R^6$。通过指数映射得到刚体变换。平移部分不是简单独立放入，严格形式包含与旋转相关的左 Jacobian。

### 6.3 左扰动和右扰动

左扰动：

$$T'=\operatorname{Exp}(\delta\xi^)T$$

右扰动：

$$T'=T\operatorname{Exp}(\delta\xi^)$$

它们对应不同坐标系下的误差，Jacobian 也不同。使用库或论文公式时必须确认扰动约定。

### 6.4 伴随矩阵

Adjoint 用于把李代数扰动在坐标系间转换：

$$\xi_A=\operatorname{Ad}_{T_{AB}}\xi_B$$

它在位姿协方差转换、速度和力变换中非常重要。简单用旋转矩阵同时旋转六维协方差会遗漏平移与旋转耦合。

## 第 7 章：概率基础

### 7.1 概率变量和条件概率

联合概率 $p(x,y)$ 描述同时发生；边缘概率通过积分/求和消去变量；条件概率：

$$p(x|y)=\frac{p(x,y)}{p(y)}$$

独立意味着 $p(x,y)=p(x)p(y)$。条件独立是图模型和贝叶斯滤波的关键。

### 7.2 期望与协方差

$$\mu=E[x]$$

$$\Sigma=E[(x-\mu)(x-\mu)^T]$$

线性变换 $y=Ax+b$：

$$E[y]=A\mu+b,\quad \Sigma_y=A\Sigma_xA^T$$

非线性变换可一阶近似：

$$\Sigma_y\approx J\Sigma_xJ^T$$

这就是误差传播，也是 EKF 协方差传播的基础。

### 7.3 高斯分布

$$p(x)=\frac1{\sqrt{(2\pi)^n|\Sigma|}}\exp\left(-\frac12(x-\mu)^T\Sigma^{-1}(x-\mu)\right)$$

指数中的 Mahalanobis 距离考虑不同维度尺度和相关性：

$$d_M^2=(x-\mu)^T\Sigma^{-1}(x-\mu)$$

可用于数据关联门限和异常检测。

### 7.4 最大似然与 MAP

最大似然：

$$\theta_{ML}=\arg\max_\theta p(D|\theta)$$

MAP 加入先验：

$$\theta_{MAP}=\arg\max_\theta p(D|\theta)p(\theta)$$

取负对数把乘积变成和。高斯观测对应加权最小二乘，高斯参数先验对应 $L_2$ 正则。

## 第 8 章：最小二乘与鲁棒估计

### 8.1 线性最小二乘

$$x^*=\arg\min_x\|Ax-b\|^2$$

正规方程：

$$A^TAx=A^Tb$$

显式构造 $A^TA$ 会平方条件数。高质量实现优先 QR 或 SVD。

### 8.2 加权最小二乘

$$x^*=\arg\min_x(Ax-b)^TW(Ax-b)$$

$W$ 常是测量协方差逆。更可信的测量权重大。

### 8.3 非线性最小二乘

$$\min_x\frac12\sum_i\|r_i(x)\|^2$$

Gauss-Newton 线性化：

$$r(x+\Delta x)\approx r(x)+J\Delta x$$

得到：

$$J^TJ\Delta x=-J^Tr$$

Levenberg-Marquardt 加阻尼：

$$(J^TJ+\lambda I)\Delta x=-J^Tr$$

$\lambda$ 大时接近梯度下降，小时时接近 Gauss-Newton。

### 8.4 鲁棒核

平方损失对离群点敏感。Huber 损失在小残差区域为二次，大残差区域转为线性。鲁棒核降低离群点影响，但不能替代正确的数据关联。

## 第 9 章：约束优化

机器人问题常包含：

$$\min_x f(x)$$

$$\text{s.t. }g_i(x)=0,\quad h_j(x)\le0$$

关节限位、碰撞、动力学和摩擦锥都是约束。简单惩罚法把约束加入损失，但权重太小违反约束，太大导致优化病态。

拉格朗日函数：

$$\mathcal L(x,\lambda,\mu)=f(x)+\sum_i\lambda_ig_i(x)+\sum_j\mu_jh_j(x)$$

KKT 条件描述约束最优点必要条件。学习 MPC 和轨迹优化前应理解可行域、活跃约束和对偶变量。

## 第 10 章：自动微分与梯度检查

PyTorch 自动微分记录计算图并使用链式法则。叶子 Tensor 的 `.grad` 默认累积，所以每步需要清零。

```python
x = torch.tensor([2.0], requires_grad=True)
y = x**3 + 2*x
y.backward()
print(x.grad)  # 3*x^2 + 2 = 14
```

### 梯度检查

比较自动梯度和中心差分：

$$g_{num,i}=\frac{f(x+he_i)-f(x-he_i)}{2h}$$

相对误差：

$$\frac{\|g_{auto}-g_{num}\|}{\|g_{auto}\|+\|g_{num}\|+\epsilon}$$

含 ReLU 不可导点、随机层或低精度时，梯度检查需避开特殊点并使用双精度。

## 第 11 章：数值稳定性

### 浮点误差

浮点数不能表示所有实数。两个接近的大数相减会丢失有效位。概率乘积容易下溢，使用 log probability：

$$\log\prod_ip_i=\sum_i\log p_i$$

### LogSumExp

$$\log\sum_i e^{x_i}=m+\log\sum_i e^{x_i-m}$$

$m=\max x_i$，避免指数溢出。softmax 和交叉熵实现依赖这种技巧。

### 归一化和尺度

状态各维尺度差异会让优化器偏向大数值维度。位置单位米、角度单位弧度、像素、力矩混合时，应选择合理归一化和损失权重。

## 第 12 章：综合数学实验

### 实验 A：位姿误差

实现两种误差：直接平移+欧拉角差，以及 SE(3) 对数误差。构造跨越 $\pm\pi$ 的角度，观察欧拉角差的不连续。

### 实验 B：点云配准

生成随机三维点，应用已知 $R,t$，加入高斯噪声和离群点。实现 SVD 配准，比较无离群、10% 离群和 RANSAC 后结果。

### 实验 C：非线性曲线拟合

拟合：

$$y=ae^{bx}+c$$

分别使用梯度下降、Gauss-Newton 和 LM，比较初值、迭代次数和最终残差。

### 实验 D：协方差传播

给二维极坐标测量 $(r,\theta)$ 及协方差，转换到笛卡尔坐标。用 Jacobian 一阶传播，再用 Monte Carlo 采样验证。角度噪声较大时观察一阶近似误差。

### 答案要点

1. 平均结果通常不满足 SO(3) 约束。
2. 输入扰动会被放大，求解病态。
3. 伪逆对奇异值取倒数，小值变成大增益。
4. 扰动所在参考坐标系与 Jacobian 定义不同。
5. $\Sigma_y=A\Sigma_xA^T$，非线性时用 Jacobian 近似。
6. $A^TA$ 会平方条件数。
7. 残差在当前点附近可线性化，忽略二阶项。
8. 不能，只能降低部分离群残差影响。
9. 数据、损失、尺度、学习率、初始化和模型表达都可能有问题。
10. 大尺度维度会主导损失和梯度，造成不合理折中。
