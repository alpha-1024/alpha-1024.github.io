# 第三册第二篇：SLAM 前端与里程计

状态估计篇解决了如何传播和更新一个状态。本篇进一步研究 SLAM 的前端：如何从连续传感器帧建立相邻位姿约束、如何选择关键帧和局部地图、怎样处理扫描期间的运动、如何判定当前约束是否退化，以及应向后端提供哪些质量信息。

前端不是“ICP 跑一下”或“特征匹配数量够了”。它面对的是数据关联、坐标系、时间、动态物体和非凸优化的组合风险。一个好的前端宁可在无纹理、低视差或纯旋转时报告不可用，也不应把错误约束送入后端让整张地图变形。

## 第 1 章：前端输出的约束契约

### 1.1 相邻约束

给定关键帧 $i$ 和当前帧 $j$，前端输出相对位姿 $T_{ij}$、残差统计、内点/有效点数量、协方差或信息矩阵 $\Omega_{ij}$、时间区间和状态码。后端使用约束的方向必须明确：

$$
{}^iT_j={}^iT_w({}^jT_w)^{-1}
$$

或者使用相反方向。变换方向错误时，轨迹可能在短距离看似连续，闭环后却出现大尺度扭曲。

### 1.2 信息矩阵不是越大越好

若误差协方差为 $\Sigma$，信息矩阵近似为 $\Omega=\Sigma^{-1}$。只有在残差模型、单位和相关性合理时，信息矩阵才可作为后端权重。用“匹配点越多所以协方差越小”的规则会在重复纹理或动态物体中产生虚假高置信度。

### 1.3 状态码

建议至少区分：`accepted`、`weak`、`degenerate`、`tracking_lost`、`time_invalid`、`dynamic_scene`、`insufficient_overlap`、`rejected_outlier`。后端可以选择只接受 accepted，或以弱权重使用 weak；故障状态必须能被监控和行为树读取。

## 第 2 章：二维激光数据预处理

### 2.1 LaserScan 的语义

第 $k$ 束距离对应角度

$$
\theta_k=\theta_{min}+k\Delta\theta.
$$

`range_min`、`range_max`、`NaN`、`Inf` 和 `intensities` 都有实际语义。把无效距离替换为最大距离会让算法误以为远处有自由空间；更安全的做法是携带 valid mask，并在射线模型中区分“测到远处”和“没有测量”。

### 2.2 转换到点云

```python
import numpy as np

def scan_to_points(ranges, angle_min, angle_increment,
                   range_min, range_max):
    ranges = np.asarray(ranges, np.float64)
    angles = angle_min + np.arange(len(ranges)) * angle_increment
    valid = np.isfinite(ranges) & (ranges >= range_min) & (ranges <= range_max)
    r = ranges[valid]
    theta = angles[valid]
    return np.column_stack((r * np.cos(theta), r * np.sin(theta))), valid
```

点的 frame 通常是激光光学 frame，不是 `base_link`。若激光不在机器人旋转中心，旋转运动时平移杠杆臂会影响扫描匹配。点云转换必须使用采样时刻的 TF。

### 2.3 去除动态和异常点

人、玻璃、镜面和近距离遮挡会产生非静态或错误点。可以使用强度、时间一致性、邻域连续性、语义掩码和局部地图预测过滤。不要把所有稀疏点都删掉，远处墙面本来就稀疏；过滤参数应随量测噪声和角分辨率调整。

## 第 3 章：二维扫描匹配

### 3.1 目标函数

设当前扫描点 $p_i$ 变换到上一帧或地图坐标，目标表面为 $S$，点到表面的距离为 $d(\cdot,S)$：

$$
\min_{\xi\in se(2)}\sum_i\rho\left(d(\exp(\xi^\wedge)p_i,S)^2\right).
$$

$\rho$ 是鲁棒核，$\xi=[\delta x,\delta y,\delta\theta]^T$ 是小位姿增量。实际实现需要为每个点找到对应线段、局部栅格梯度或最近邻。

### 3.2 点到点 ICP

点到点 ICP 交替寻找最近邻和求解二维刚体变换。它对初值要求较高，在长直墙、重复柱子和低重叠环境容易出现沿墙滑移。若目标点稀疏，最近邻距离可能被角度采样影响。

### 3.3 点到线匹配

对激光点 $p_i$，目标局部线段上点 $q_i$ 和法线 $n_i$，残差

$$
r_i=n_i^T(Tp_i-q_i).
$$

点到线更符合二维激光观测：沿墙方向的误差不应被强烈惩罚。对小旋转 $\delta\theta$，$Tp\approx p+[\delta\theta]_\times p+t$，可写出 1×3 Jacobian。收集所有对应形成 $J$，通过加权最小二乘求解。

```python
def solve_point_to_line(points, targets, normals, weights=None):
    points = np.asarray(points, np.float64)
    targets = np.asarray(targets, np.float64)
    normals = np.asarray(normals, np.float64)
    if points.shape != targets.shape or points.shape != normals.shape:
        raise ValueError("point, target and normal shapes must match")
    if points.ndim != 2 or points.shape[1] != 2 or len(points) < 3:
        raise ValueError("need at least three 2D correspondences")
    residual = np.sum(normals * (points - targets), axis=1)
    J = np.column_stack((
        normals[:, 0],
        normals[:, 1],
        -normals[:, 0] * points[:, 1] + normals[:, 1] * points[:, 0],
    ))
    if weights is None:
        weights = np.ones(len(points))
    W = np.diag(np.asarray(weights, np.float64))
    H = J.T @ W @ J
    if np.linalg.eigvalsh(H)[0] < 1e-9:
        raise ValueError("degenerate scan geometry")
    delta = -np.linalg.solve(H, J.T @ W @ residual)
    return delta, residual, H
```

代码中的符号与坐标约定要用合成变换验证。令真实扫描旋转 5°、平移 0.1 m，生成目标点并加噪声，确认增量方向能降低残差；符号错时残差会反而上升。

### 3.4 多分辨率扫描匹配

粗层使用稀疏点和较大搜索半径捕获大运动，细层使用完整点和较小阈值精化。每层都记录内点、RMSE、Hessian 特征值和增量。粗到细不能弥补完全错误的初值或没有几何结构。

## 第 4 章：视觉里程计前端

### 4.1 特征法流程

1. 在当前图像提取关键点和描述子。
2. 与上一帧或局部关键帧匹配。
3. 比率、双向和空间分布过滤。
4. 根据单目/双目/RGB-D 使用本质矩阵、PnP 或 3D-3D 配准。
5. RANSAC 后用内点优化位姿。
6. 检查视差、正深度、重投影、运动连续性和退化。
7. 更新轨迹和关键帧。

### 4.2 单目初始化

单目两帧从本质矩阵恢复的平移只有方向。初始化需要足够视差，并对三角化点进行正深度和重投影检查。整体尺度可任意选定，后续通过轮速、IMU、双目基线、已知物体或回环约束恢复/稳定。

纯旋转或低视差时，系统应保持未初始化或仅更新旋转，不应输出任意尺度平移。

### 4.3 RGB-D 和双目

已知深度的 2D-3D PnP 具有米制尺度；双目三角化同样依赖基线和视差。深度孔洞、左右遮挡和时间错位会让对应失效。把所有深度点当作高精度真值会导致姿态过度自信，应根据深度误差给观测权重。

### 4.4 直接法

直接法在图像像素上最小化光度误差：

$$
E(T)=\sum_{p\in\Omega}
\rho\left(I_2(\pi(T\Pi^{-1}(p,D(p))))-I_1(p)\right).
$$

它利用更多像素，不依赖显式描述子，但依赖曝光/响应稳定、深度和初值。相机自动曝光、反光、动态物体和大运动会破坏亮度模型。工程系统常使用粗到细金字塔、曝光模型和梯度像素选择。

## 第 5 章：光流和特征轨迹管理

### 5.1 轨迹对象

每条轨迹保存 `track_id`、首次关键帧、当前像素、历史长度、前后向误差、观测尺度、所属地图点和质量状态。只保存当前匹配无法判断一条轨迹是否长期稳定。

### 5.2 轨迹过滤

前后向光流误差、RANSAC 几何残差、速度突变、越界、遮挡和重复特征都可以使轨迹失效。删除轨迹要记录原因，统计不同场景的失败比例。过度保留错误轨迹会污染后端；过度删除会让系统频繁初始化。

### 5.3 特征均匀性

用网格限制每格特征数，避免全部点集中在一面海报。均匀覆盖更利于估计旋转、平移和滚动快门效应。对局部地图选择关键帧时，应优先补充新区域而不是重复已有纹理。

## 第 6 章：关键帧与局部地图

### 6.1 关键帧触发

可根据以下信号触发：

- 与上一关键帧平移/旋转超过阈值。
- 有效跟踪点低于阈值。
- 新可见区域或共视关系不足。
- 时间间隔超过上限。
- 光照或视角变化使旧描述子不可靠。

只按固定时间插入关键帧会在静止时产生冗余，在快速运动时又过稀。阈值应结合地图点、视差和后端负载。

### 6.2 局部地图

局部地图包含当前关键帧的共视关键帧及其地图点。匹配局部地图比只匹配上一帧能提高短暂跟踪失败后的恢复能力，但计算量和错误关联风险增加。地图点要记录观测关键帧数、平均视角、尺度、重投影残差和最近更新时间。

### 6.3 地图点剔除

删除长期未观测、重投影误差高、深度不稳定、视角过窄或被动态物体生成的点。不要因为一次遮挡立即删除；使用最小观测次数、连续失败计数和生命周期状态。

## 第 7 章：运动畸变

### 7.1 激光扫描畸变

一帧 LaserScan 在扫描时间区间 $[t_0,t_1]$ 采集不同角度。若机器人在运动，点 $p_i$ 属于不同传感器位姿 $T(t_i)$。应通过 IMU/轮速插值把点变换到统一参考时刻：

$$
p_i^{ref}=T(t_{ref})^{-1}T(t_i)p_i.
$$

使用帧头时间代替每束时间会在快速旋转时把墙扫成弧形。驱动必须提供 `time_increment` 或每束时间；没有时间信息时只能承认去畸变能力有限。

### 7.2 插值与外推

在相邻 IMU/里程计状态之间插值，超过缓存范围的时间不应无条件外推。外推时间越大，误差越不确定。输出质量应携带最大插值/外推年龄。

### 7.3 相机滚动快门

图像不同扫描行对应不同相机姿态。特征应依据行时间去畸变，或在快速运动时降低曝光/使用全局快门。若前端模型假设全局快门，残差可能随像素行有规律变化；这也是诊断信号。

## 第 8 章：前端退化检测

### 8.1 Hessian 特征值

线性化问题正规矩阵 $H=J^TWJ$ 的特征值反映约束强弱。条件数过大说明存在弱方向。阈值依赖单位和缩放，不能跨系统直接比较。报告最小特征值、条件数和对应方向，帮助解释走廊或墙面退化。

### 8.2 几何退化例子

- 激光在长直走廊：沿走廊方向平移和绕垂直轴可能弱约束。
- 视觉纯旋转：平移尺度不可观。
- 单一平面：深度方向和某些旋转弱约束。
- 点集中在图像中心：相机旋转/平移分离较差。
- 动态人群占据多数点：估计跟随动态主体。

### 8.3 不要把退化硬修正

可使用 IMU、轮速、先验或后端约束补足弱方向，但必须在信息矩阵中表达来源。直接对位姿增量做任意限幅可能暂时稳定画面，却破坏概率语义。更安全做法是降低约束权重、保持预测并报告退化状态。

## 第 9 章：前端质量评分

把多个信号归一化为质量分数不是为了制造一个神秘数字，而是方便状态机决策。质量报告至少包括：有效匹配、内点率、空间覆盖、视差、重投影/点到线残差、Hessian 条件、动态比例、时间年龄和运动先验差异。

```python
from dataclasses import dataclass

@dataclass(frozen=True)
class FrontendDiagnostics:
    status: str
    inliers: int
    inlier_ratio: float
    coverage: float
    median_parallax: float
    rmse: float
    condition_number: float
    time_age_ms: float

def accept_frontend(d: FrontendDiagnostics):
    if d.status != "ok":
        return False
    if d.inliers < 30 or d.inlier_ratio < 0.35:
        return False
    if d.coverage < 0.25 or d.rmse > 2.0:
        return False
    if d.condition_number > 1e5 or d.time_age_ms > 100:
        return False
    return True
```

门槛必须用带真值的序列选择，测试集只评估。`inlier_ratio` 高但覆盖低的单区域匹配应拒绝；`rmse` 低但视差接近零的单目平移也应标记不可观。

## 第 10 章：局部子图和扫描到地图

### 10.1 为什么不只对上一帧

上一帧可能模糊、被动态物体遮挡或视差太小。局部子图把最近若干关键帧或体素地图融合，提供更多稳定几何和恢复能力。地图融合时要处理重复点、动态残留和位姿不确定性，不能无限累加所有点。

### 10.2 子图更新

固定空间窗口或关键帧数量，当前位姿移动后删除远处内容；对点云使用体素哈希或占据栅格压缩。保存每个体素的观测次数、时间和动态一致性，旧点不能与新动态观测同权。

### 10.3 扫描到地图的初值

轮速/IMU 提供预测，前端以预测为初值进行 scan-to-map。初值协方差可以转成搜索窗口；预测不确定性大时，增大匹配范围但降低接受置信度。局部搜索失败后应尝试重定位或回环候选，不应无限迭代当前局部极小。

## 第 11 章：前端与后端的边界

前端负责局部数据关联和短期约束，后端负责历史变量联合优化、回环和全局一致性。前端不应私自把历史轨迹整体“拉直”，后端也不应相信没有质量元数据的约束。

约束消息建议包含：`from_id`、`to_id`、相对变换、协方差/信息矩阵、残差、内点、质量状态、传感器来源、采样时间区间和版本。后端记录拒绝的约束及原因，便于回放。

错误回环的破坏力远大于普通相邻约束。回环候选必须经历外观检索、几何验证、空间一致性和多帧确认；前端在动态或重复环境中宁可不提供回环。

## 第 12 章：视觉-激光混合前端

视觉有纹理和语义，激光有几何和光照鲁棒性。可以松耦合地融合两种里程计，也可以在共同图优化中使用视觉重投影和激光点到面残差。松耦合易实现但信息相关性难表达；紧耦合潜力高但标定、同步和优化复杂。

融合前先验证外参、时间和坐标。若一套传感器发布 `base_link`，另一套发布 `sensor`，不能仅凭轨迹相似判断对齐。用静态标定板、平面和共同运动验证相对变换。

## 第 13 章：动态场景处理

### 13.1 几何一致性

连续帧中不符合刚体运动的点可以被标记为动态。使用多模型 RANSAC 或将残差随时间聚类。最大一致模型可能属于一辆大车而非静态背景，因此需要语义先验和历史地图。

### 13.2 语义剔除

人、车、动物等类别可在前端匹配前剔除或降低权重。语义模型漏检会残留动态点，误检又会删掉静态结构。动态过滤需与几何残差联合，而非完全依赖单帧分割。

### 13.3 可恢复性

动态比例升高时降低前端权重、缩短局部地图寿命或等待静态区域出现。报告 dynamic ratio 和被剔除点位置；若整幅视野都是动态物体，系统应进入 tracking lost 或低速安全状态。

## 第 14 章：综合实验一——二维激光前端

### 数据

在仿真中生成走廊、房间、柱子、窄门和动态障碍场景，加入不同角分辨率、距离噪声、丢束和运动。再采集一段真实 rosbag，保存每束时间信息。

### 实现

实现点到线线性化、最近邻/线段对应、鲁棒核、多尺度迭代、Hessian 退化检测和前端诊断。使用轮速/IMU 作为初值。对每个 frame 输出位姿、内点、RMSE、条件数、最小视差和状态码。

### 评估

使用仿真真值计算相对姿态误差和累计漂移，分别切片正常、走廊、低重叠、动态和快速旋转。绘制初值扰动下的成功域。真实数据没有精确真值时，用闭环、标记和地图墙面残差作为辅助证据，并明确限制。

## 第 15 章：综合实验二——视觉/RGB-D 里程计

实现特征法 RGB-D 里程计：ORB/网格化 → Hamming KNN/比率 → 2D-3D PnP RANSAC → 内点优化 → 深度正值和视差检查 → 关键帧插入。额外实现前后向光流作为短期跟踪。

比较三种模式：只上一帧、局部关键帧、局部关键帧加轮速先验。记录跟踪成功率、漂移、重定位时间、GPU/CPU 时间和在模糊、低纹理、动态目标中的失败分类。

## 第 16 章：前端故障排查练习

### 练习一：轨迹突然镜像

检查旋转矩阵行列式、左右手坐标、角度符号、TF 方向和图像坐标 y 轴。用一个已知正向平移和一个已知顺时针旋转的合成样例，逐模块比较输出。

### 练习二：走廊中沿轴漂移

查看 Hessian 小特征值和点覆盖，确认是否是几何不可观，而不是简单调大匹配阈值。加入轮速/IMU 先验、侧向结构或在地图中使用墙端特征，观察弱方向是否改善。

### 练习三：动态人群中轨迹跟随人

画出内点在图像和地图中的位置，比较语义过滤前后。若动态主体占多数，最大一致模型会选择错误运动；系统应降低质量或剔除动态区域，不能把高内点率当作成功。

### 练习四：快速旋转时墙体弯曲

检查 LaserScan 每束时间、TF 插值和外推，关闭去畸变做对照。若弯曲随速度和扫描时间增长，优先修复运动补偿；重新调 ICP 不能消除物理采样畸变。

## 第 18 章：参考答案

### 一、概念题答案

1. 后端需要变换方向和时间连接变量，协方差/信息矩阵决定约束权重，状态码表示退化、动态和跟踪失败。没有这些元数据，后端无法区分强可靠约束和危险伪约束。

2. 点到线只惩罚法向距离，更符合墙面扫描，沿线切向误差不被不必要地惩罚，通常收敛更快。长直墙会使沿墙平移和绕墙法线等方向弱可观，Hessian 条件数变大。

3. 纯旋转单目平移/尺度不可观；走廊沿轴方向结构重复，沿走廊平移和部分旋转弱约束；单平面点云在平面内切向和绕法线方向弱约束。实际有限边界会提供一些弱信息，但不应假定强可观。

4. 固定时间会在静止时产生冗余，在快速运动或视差变化时过稀。应结合位姿变化、视差、跟踪点数、共视、区域新颖性和后端负载触发。

5. 扫描一帧内不同束在不同姿态采样，若按同一时刻处理，运动会把静态结构扭曲。用每束时间和 IMU/里程计插值，将各点变换到统一参考时刻；没有时间信息只能限制速度或承认退化。

### 二、代码题答案

点到线实现需要计算残差 $n^T(p-q)$ 和含旋转项的 Jacobian，构造加权 $H=J^TWJ$，检测最小特征值后求增量，并把增量应用到 SE(2)。合成测试生成随机点、已知变换和法线，加噪声后检查残差下降及估计误差；共线/单法线样本应拒绝或标记退化。

质量输入包括有效匹配/内点、内点率、空间覆盖、视差、残差、Hessian 特征值、动态比例、时间年龄和运动先验差异。拒绝条件应覆盖点数不足、低覆盖、低视差、条件数过大、残差超限、过期和动态比例过高。输出状态码与所有诊断，不用一个分数掩盖具体原因。

局部地图按关键帧共视和空间窗口维护，点记录观测数、残差、视角、最后观测和动态计数；短暂遮挡不立即删除，连续失败或高残差才剔除。体素压缩重复点，动态不一致点降低权重或淘汰，地图大小和更新时间受明确预算控制。

### 三、系统分析答案

扇形拉伸可能来自：单目尺度或深度错误；滚动快门/运动畸变；错误相机内参或畸变重复；坐标变换方向；错误匹配虽内点高但集中局部/重复纹理；回环或后端错误约束；时间戳错位；点深度符号或单位。排查先保存同一帧输入，比较相机坐标和世界坐标；检查内点空间和重投影；用合成/标定板验证几何；查看误差随速度、图像行和距离变化；暂停后端只看前端；最后检查闭环与信息矩阵。

走廊漂移是几何可观性不足，不是迭代次数不足。先看 Hessian 弱特征值、对应点分布和初值扰动成功域。改进实验包括加入轮速/IMU 先验并正确给协方差；增加侧向柱子/墙端等结构；使用局部子图和关键帧；融合视觉或人工标记；在行为层降低速度并触发重新定位。比较不同走廊方向、运动速度和传感器组合的漂移，验证哪一约束真正补足弱方向。
