# 第二册：视觉与三维感知

## 第 1 章：从三维世界到二维图像

相机把三维点投影到二维像素。针孔模型中，相机坐标点 $P_c=[X,Y,Z]^T$ 满足：

$$u=f_x\frac{X}{Z}+c_x,\quad v=f_y\frac{Y}{Z}+c_y$$

$f_x,f_y$ 是以像素为单位的焦距，$c_x,c_y$ 是主点。写成矩阵：

$$
\begin{bmatrix}u\\v\\1\end{bmatrix}
\sim
K\begin{bmatrix}X\\Y\\Z\end{bmatrix},\quad
K=\begin{bmatrix}f_x&0&c_x\\0&f_y&c_y\\0&0&1\end{bmatrix}
$$

符号 $\sim$ 表示齐次坐标意义下相等。投影会丢失尺度：同一条射线上的不同三维点可能落在同一像素。深度相机、双目或多视图几何用于恢复尺度。

### 坐标系约定

OpenCV 相机坐标常用 x 向右、y 向下、z 向前；ROS REP-103 的机器人坐标常用 x 向前、y 向左、z 向上；光学坐标系通常另有约定。转换错误会出现镜像、旋转 90 度或上下颠倒。

### 畸变

真实镜头存在径向和切向畸变。径向畸变常写为：

$$x_d=x(1+k_1r^2+k_2r^4+k_3r^6)$$

广角镜头边缘误差更明显。标定的目的不是得到“漂亮参数”，而是让重投影误差足够小且在整幅图像分布均匀。

## 第 2 章：相机标定

### 采集原则

- 标定板覆盖画面中心和四角。
- 包含不同距离、角度和倾斜姿态。
- 避免所有图片几乎相同。
- 避免运动模糊、过曝和标定板弯曲。
- 明确格子尺寸单位。

OpenCV 基本流程：检测角点、构建三维棋盘点、调用 `calibrateCamera`、计算每张图重投影误差、剔除异常图片后重新标定。

```python
import cv2
import numpy as np

pattern = (9, 6)
square_size = 0.024
obj = np.zeros((pattern[0] * pattern[1], 3), np.float32)
obj[:, :2] = np.mgrid[0:pattern[0], 0:pattern[1]].T.reshape(-1, 2)
obj *= square_size

ok, corners = cv2.findChessboardCorners(gray, pattern)
if ok:
    corners = cv2.cornerSubPix(
        gray, corners, (11, 11), (-1, -1),
        criteria=(cv2.TERM_CRITERIA_EPS + cv2.TERM_CRITERIA_MAX_ITER, 30, 1e-3)
    )
```

平均误差不能掩盖局部异常。应保存每张图误差并绘制角点空间分布。若标定板只出现在中心，中心误差可能很小，边缘仍然很差。

## 第 3 章：图像处理与特征

### 颜色和归一化

OpenCV 默认 BGR，许多深度模型使用 RGB。模型还可能要求 `[0,1]`、ImageNet 均值方差或特定尺寸。颜色顺序错误不会报异常，但精度会显著下降。

### 卷积

卷积核在局部邻域计算加权和，可用于平滑、边缘和特征提取。高斯滤波降低高频噪声但会模糊边缘；双边滤波在一定程度上保留边缘但计算更慢。

### 特征匹配

传统流程：检测关键点、计算描述子、匹配、比率测试、几何验证。仅凭描述子距离会产生大量错误匹配，必须使用 RANSAC 估计单应性、本质矩阵或基础矩阵过滤。

## 第 4 章：深度图与点云

给定像素 $(u,v)$ 和深度 $Z$：

$$X=(u-c_x)Z/f_x,\quad Y=(v-c_y)Z/f_y$$

可以把深度图反投影成点云。必须确认深度单位：有的设备输出毫米整数，有的输出米浮点。

```python
def depth_to_points(depth, K, scale=1000.0):
    fy, fx = K[1, 1], K[0, 0]
    cy, cx = K[1, 2], K[0, 2]
    v, u = np.indices(depth.shape)
    z = depth.astype(np.float32) / scale
    valid = (z > 0.1) & (z < 5.0)
    x = (u - cx) * z / fx
    y = (v - cy) * z / fy
    return np.stack([x[valid], y[valid], z[valid]], axis=1)
```

### 点云预处理

- PassThrough：按坐标范围裁剪。
- Voxel Grid：体素降采样。
- Statistical Outlier Removal：统计离群点过滤。
- Radius Outlier Removal：半径邻域过滤。
- 法线估计：依赖邻域尺度。

滤波参数必须与点云尺度和密度匹配。体素太大会删除小物体，太小则没有加速效果。

## 第 5 章：RANSAC 与 ICP

### RANSAC

RANSAC 从少量样本拟合模型，用一致集判断模型质量。平面拟合流程：随机选三个不共线点，得到平面，计算所有点到平面的距离，统计阈值内点数，多次迭代保留最佳模型。

阈值不能脱离传感器噪声设定。深度噪声随距离增加时，固定阈值可能在近处过松、远处过严。

### ICP

ICP 交替执行：寻找对应点、最小化对应误差、更新变换。它是局部优化，需要合理初值；对称物体、重复结构和低重叠会失败。

评价 ICP 不能只看最终 fitness，还应检查：重叠率、初始误差、是否落入错误局部极小值，以及变换在物理上是否合理。

## 第 6 章：PnP 与位姿估计

PnP 根据三维点与二维像素对应关系估计相机位姿：

$$s\tilde p=K[R|t]P$$

至少需要足够且分布合理的对应点。所有点接近共线或集中在小区域会导致病态。使用 `solvePnPRansac` 可过滤部分错误对应。

```python
ok, rvec, tvec, inliers = cv2.solvePnPRansac(
    object_points,
    image_points,
    camera_matrix,
    dist_coeffs,
    reprojectionError=3.0,
    confidence=0.99,
    iterationsCount=100,
)
R, _ = cv2.Rodrigues(rvec)
```

得到的通常是“物体到相机”还是“世界到相机”取决于输入点定义。发布 TF 前必须明确方向，必要时求逆。

## 第 7 章：深度学习感知

### 数据划分

随机按图片划分可能泄漏：同一视频相邻帧几乎相同。更合理的是按场景、物体实例或录制序列划分。测试集应包含未见过的背景、距离和光照。

### 检测与分割

检测输出框和类别，实例分割输出每个实例像素掩码。机器人抓取常需要比矩形框更精确的轮廓，但分割推理成本更高。选择模型时比较任务成功率，而不是只比较 mAP。

### 指标

- Precision：预测为正的样本中有多少正确。
- Recall：真实正样本中有多少被找到。
- IoU：预测区域和真实区域的交并比。
- mAP：不同类别和阈值下的平均精度。

机器人系统还应报告端到端延迟、漏检连续时长和置信度校准。单帧 mAP 高但延迟 500ms，可能无法用于实时控制。

## 第 8 章：RGB-D 三维定位综合实验

### 系统结构

```text
RGB + Depth + CameraInfo
  → 时间同步
  → 检测/分割
  → 掩码内深度过滤
  → 三维点统计
  → camera_link 到 base_link 的 TF
  → PoseWithCovariance 发布
```

不要只取框中心一个深度像素。中心可能落在孔洞或背景。更稳健的方法是对掩码内有效深度做中值统计，过滤边缘和离群点，并根据样本分布估计不确定性。

### 时间同步

RGB 和深度不是同一时刻会产生空间错位。ROS2 可以使用 message_filters 的近似同步，但容差必须记录。机器人或目标运动越快，允许时间差越小。

### 测试设计

建立固定测试表：

| 距离 | 水平位置 | 光照 | 遮挡 | 重复次数 |
| ---: | --- | --- | --- | ---: |
| 0.5m | 左/中/右 | 正常 | 无 | 10 |
| 1.0m | 左/中/右 | 正常 | 无 | 10 |
| 1.5m | 左/中/右 | 弱光 | 部分 | 10 |

测量真实位置，报告平移误差均值、P95、最大值、检测成功率和端到端延迟。

### 失败分析

- 深度孔洞：使用邻域有效值和时序滤波。
- 反光/透明物体：深度传感原理受限，可能需要双目或多视角。
- 遮挡：检测置信度和位姿不确定性下降。
- TF 超时：检查时间戳、缓存和处理延迟。
- 位置抖动：检查深度噪声、目标掩码变化和滤波延迟。

## 第二册检查题

1. 为什么单目图像不能直接恢复绝对尺度？
2. 为什么标定板必须覆盖图像边缘？
3. 深度图转点云时最容易犯的单位错误是什么？
4. ICP 为什么需要初值？
5. PnP 输出变换方向如何确认？
6. 为什么同一视频的相邻帧不能随机分到训练集和测试集？
7. RGB-D 定位为什么不应只读框中心深度？

### 答案摘要

1. 投影丢失深度尺度，同一射线上不同点可映射到同一像素。
2. 否则边缘畸变参数缺乏约束。
3. 把毫米当作米，造成 1000 倍尺度错误。
4. ICP 是局部优化，初值差时对应关系错误。
5. 查看函数定义与输入三维点坐标系，用已知点重投影并验证，必要时求逆。
6. 数据高度相似会泄漏，测试指标虚高。
7. 中心可能是背景、孔洞或噪声，掩码统计更稳健。
