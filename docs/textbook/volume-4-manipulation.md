# 第四册：机械臂规划与控制

## 第 1 章：机械臂系统分层

机械臂抓取不是调用一次 `move()`：

```text
任务目标
→ 目标/抓取位姿
→ 逆运动学
→ 碰撞约束下的路径规划
→ 时间参数化轨迹
→ 关节控制器
→ 驱动器与电机
→ 编码器/力传感反馈
```

每层失败现象不同。规划失败可能是目标不可达或碰撞；控制失败可能是增益、摩擦或通信延迟；抓取失败还可能来自感知误差和夹爪接触。

## 第 2 章：正运动学

机械臂由关节和连杆组成。正运动学根据关节变量 $q$ 求末端位姿：

$$T_{0n}(q)=T_{01}(q_1)T_{12}(q_2)\cdots T_{n-1,n}(q_n)$$

DH 参数用 $a,\alpha,d,\theta$ 描述相邻坐标系，但工程中 URDF 更常用于模型描述。无论采用哪种方法，都必须验证零位姿和关节正方向。

二维二连杆：

$$x=l_1\cos q_1+l_2\cos(q_1+q_2)$$

$$y=l_1\sin q_1+l_2\sin(q_1+q_2)$$

```python
import numpy as np

def fk_2link(q, lengths=(1.0, 0.8)):
    q1, q2 = q
    l1, l2 = lengths
    return np.array([
        l1*np.cos(q1) + l2*np.cos(q1+q2),
        l1*np.sin(q1) + l2*np.sin(q1+q2),
    ])
```

验证方法：零位、单关节旋转、数值结果与 RViz 模型、有限差分与雅可比。

## 第 3 章：逆运动学

逆运动学根据目标位姿求关节角：

$$q^*=\arg\min_q \|f(q)-x^*\|$$

它可能无解、多解或在关节限位内无解。解析法速度快但依赖结构；数值法通用但需要初值并可能陷入局部解。

数值迭代：

$$\Delta q=J^+(q)e$$

$J^+$ 是伪逆，$e$ 是末端误差。靠近奇异位形时伪逆会产生很大关节速度，可使用阻尼最小二乘：

$$J^+=J^T(JJ^T+\lambda^2I)^{-1}$$

IK 成功不等于轨迹可执行。解可能贴近限位、发生自碰撞或与环境碰撞，因此还需规划和约束检查。

## 第 4 章：雅可比与奇异性

雅可比连接关节速度和末端速度：

$$\dot x=J(q)\dot q$$

也连接末端力和关节力矩：

$$\tau=J^T(q)F$$

奇异位置下 $J$ 降秩，某些末端方向无法产生速度，或需要极大关节速度。实际控制应监控最小奇异值、条件数和速度限幅。

数值检查雅可比：

```python
def numerical_jacobian(fk, q, eps=1e-6):
    q = np.asarray(q, dtype=float)
    base = fk(q)
    J = np.zeros((base.size, q.size))
    for i in range(q.size):
        perturbed = q.copy()
        perturbed[i] += eps
        J[:, i] = (fk(perturbed) - base) / eps
    return J
```

解析雅可比与数值雅可比不一致时，先检查坐标系、旋转表示和关节轴。

## 第 5 章：轨迹规划

路径只描述几何位置序列，轨迹还包含时间、速度和加速度。直接向控制器发送离散路径点会造成速度突变。

### 三次多项式

$$q(t)=a_0+a_1t+a_2t^2+a_3t^3$$

四个系数可满足起终点位置和速度约束。五次多项式还能约束起终点加速度。

轨迹必须满足：

- 关节位置限制。
- 速度和加速度限制。
- 控制周期和插值方式。
- 机械臂负载和动力学能力。

时间缩放不是简单把时间乘常数。多关节应同步到达，并检查缩放后速度、加速度和 jerk。

## 第 6 章：运动规划与碰撞

配置空间中的一个点表示整组关节角。障碍物在配置空间形成复杂禁区。采样规划器不显式构造完整禁区，而是采样状态并做碰撞检查。

### RRT/RRT-Connect

RRT 从树中选择近邻，向随机样本扩展。RRT-Connect 双向生长，常用于快速找到可行路径。它们擅长高维空间，但路径可能绕远且不平滑。

### PRM

PRM 预先采样路线图，适合固定环境中的多次查询。环境频繁变化时需更新碰撞边。

### 轨迹优化

把平滑、碰撞、长度和动力学写入目标函数，迭代优化初始轨迹。它依赖初值，可能陷入局部最优。

碰撞模型通常是简化网格或基本几何体。视觉模型和碰撞模型不一致会导致“看起来没碰，规划器认为碰撞”或相反。

## 第 7 章：URDF、SRDF 与 MoveIt2

### URDF

描述 link、joint、visual、collision、inertial、limit。常见错误：

- 网格单位毫米/米混淆。
- joint origin 或 axis 错误。
- collision 网格过于复杂。
- 惯量矩阵不合理。
- mimic joint 配置缺失。

### SRDF

描述规划组、末端执行器、命名状态和允许碰撞矩阵。自碰撞矩阵错误可能让规划过慢或忽略真实碰撞。

### MoveIt2 工作流

1. 更新 PlanningScene。
2. 设置 planning group 和起始状态。
3. 设置关节或位姿目标。
4. 调用 IK 和规划器。
5. 时间参数化。
6. 执行并监控结果。

规划失败时记录 MoveIt error code，并分别测试 IK、碰撞和规划，不要只重复调用。

## 第 8 章：ros2_control

ros2_control 把上层控制器与不同硬件抽象分离：

- Hardware Interface：读状态、写命令。
- Controller Manager：加载和切换控制器。
- Joint State Broadcaster：发布关节状态。
- Joint Trajectory Controller：执行轨迹。

硬件接口必须定义 command/state interface，例如 position、velocity、effort。控制器期待 position，而硬件只暴露 velocity 时无法直接连接。

### 实时注意

- 控制循环中避免动态内存分配。
- 不在实时线程进行磁盘和网络阻塞操作。
- 使用实时安全的数据交换。
- 监控周期抖动和 deadline miss。

普通 Linux 不等于硬实时系统。对于高性能力控，应评估实时内核、EtherCAT 等通信和控制器位置。

## 第 9 章：PID、前馈与阻抗控制

### PID

$$u=K_pe+K_i\int e\,dt+K_d\dot e$$

- P 提供主要纠偏。
- I 消除稳态误差，但会积分饱和。
- D 抑制快速变化，但对噪声敏感。

调参先从 P 开始，确保方向和单位正确，再加入 D，最后按需加入 I。实现 anti-windup 和输出限幅。

### 前馈

如果知道期望速度、加速度或动力学，可加入前馈减轻反馈负担：

$$u=u_{ff}+u_{fb}$$

### 阻抗控制

阻抗控制让机器人表现为虚拟弹簧阻尼系统：

$$F=K(x_d-x)+D(\dot x_d-\dot x)$$

适合接触任务，但稳定性受控制频率、延迟、刚度和环境影响。没有力矩接口或力传感器时只能实现近似行为。

## 第 10 章：抓取规划

抓取包括：预抓取、接近、闭合、抬升、搬运、放置。单个抓取位姿还要考虑：

- 夹爪宽度和物体尺寸。
- 接近方向是否无碰撞。
- 末端姿态是否可达。
- 闭合后是否形成稳定接触。
- 抬升轨迹是否碰撞。

### 感知到规划的接口

感知位姿应带时间戳、坐标系和不确定性。规划前转换到 planning frame，并检查 TF 时间。目标持续运动时，旧位姿可能已经无效。

### 抓取评估

对每类物体做多次实验：

| 指标 | 含义 |
| --- | --- |
| 感知成功率 | 能否输出有效目标位姿 |
| 规划成功率 | 有效位姿中能否找到路径 |
| 执行成功率 | 轨迹是否正常完成 |
| 抓取成功率 | 是否稳定拿起并保持 |
| 总任务成功率 | 从输入到放置完整成功 |

分层指标可以定位瓶颈。总成功率低不等于规划器差。

## 第 11 章：综合项目

完成一个仿真机械臂 RGB-D 抓取系统：

1. 发布 RGB-D 和相机参数。
2. 检测目标并估计三维位置。
3. 用 TF 转换到机械臂基座。
4. 生成多个抓取候选。
5. IK、碰撞检查和路径规划。
6. 通过 ros2_control 执行。
7. 监测结果并自动重试。

### 验收

- 至少 5 类物体，每类 20 次。
- 总成功率、各阶段成功率和 P95 时延。
- 目标位姿加入已知噪声，绘制成功率变化。
- 故意制造不可达和碰撞目标，系统应安全拒绝。
- 保存失败 rosbag 和 PlanningScene。

## 第四册检查题

1. IK 有解为什么仍可能规划失败？
2. 雅可比接近奇异时会发生什么？
3. 路径和轨迹有什么区别？
4. 为什么碰撞网格通常要简化？
5. ros2_control 的 hardware interface 解决什么问题？
6. PID 的积分饱和是什么？
7. 为什么抓取系统要报告分层成功率？

### 答案摘要

1. IK 解可能碰撞、越限，或从当前状态无法无碰撞到达。
2. 某些方向失去运动能力，伪逆可能生成极大关节速度。
3. 路径是几何序列，轨迹包含时间、速度和加速度。
4. 复杂网格增加碰撞检测成本且可能包含视觉细节噪声。
5. 把控制器与具体硬件读写方式解耦。
6. 输出饱和时误差仍被积分，解除饱和后产生巨大过冲。
7. 区分感知、规划、执行和夹持问题，才能针对改进。
